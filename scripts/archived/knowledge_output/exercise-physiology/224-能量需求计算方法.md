## 摘要

运动人群的能量需求可通过多种公式估算，包括Harris-Benedict、DRI和Mifflin-St. Jeor方程。这些公式基于年龄、体重、身高等参数，但运动员需根据自身情况调整。

## 核心原则

1. **基础代谢率估算**：Harris-Benedict公式适用于男女，分别计算静息能量消耗。
2. **活动因子调整**：DRI方法通过加入活动因子调整基础代谢率，以估算全天能量需求。

## 适用人群

| 人群 | 适用性 | 注意事项 |
|------|--------|---------|
| 初学者 | ✅ | 可使用基础公式估算日常能量需求 |
| 中级训练者 | ✅ | 需结合活动因子进行更精确的估算 |
| 高级训练者 | ✅ | 应根据自身代谢特点进行个性化调整 |

## 具体参数

| 参数 | 推荐值 | 范围 | 说明 |
|------|--------|------|------|
| Harris-Benedict公式（女性） | 655 + 9.6·体重(kg) + 1.8·身高(cm) – 4.7·年龄 | - | 用于估算静息能量消耗 |
| Harris-Benedict公式（男性） | 66 + 13.7·体重(kg) + 5.0·身高(cm) – 6.8·年龄 | - | 用于估算静息能量消耗 |
| DRI方法（女性） | 354 – 6.91·年龄 + (9.36·体重(kg) + 726·身高(m)) | - | 需结合活动因子计算全天能量需求 |
| DRI方法（男性） | 662 – 9.53·年龄 + (15.91·体重(kg) + 539.6·身高(m)) | - | 需结合活动因子计算全天能量需求 |
| Mifflin-St. Jeor公式（女性） | (9.99·体重(kg) + 6.25·身高(cm) – 4.92·年龄) – 161 | - | 更适用于超重或肥胖人群 |
| Mifflin-St. Jeor公式（男性） | (9.99·体重(kg) + 6.25·身高(cm) – 4.92·年龄) + 5 | - | 更适用于超重或肥胖人群 |

## 禁忌症与注意事项

- ⚠️ 运动员需注意公式适用于一般人群，可能需调整
- ⚠️ 实际能量需求应结合个体差异和训练强度进行修正
- ⚠️ 超重或肥胖人群建议使用Mifflin-St. Jeor公式

## 实践建议

1. 使用Harris-Benedict公式估算基础代谢率，再结合活动因子计算每日总能量需求。
2. 超重或肥胖人群应使用Mifflin-St. Jeor公式以提高估算准确性。
3. 运动员应根据自身训练强度和营养状况，对估算结果进行适当调整。
