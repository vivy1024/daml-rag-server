## 摘要

本文介绍了运动康复评估的六步流程，包括体态评估、动作模式评估、呼吸模式评估、关节活动度评估、步态评估和肌肉力量测试，强调评估是康复的基础，需要系统性与准确性。

## 核心原则

1. **系统性评估**: 评估应从体态到动作模式，再到呼吸、关节活动度、步态和肌肉力量，逐步深入。
2. **评估导向康复**: 通过准确评估发现问题，才能制定针对性的康复方案。

## 适用人群

| 人群 | 适用性 | 注意事项 |
|------|--------|---------|
| 初学者 | ⚠️ | 需要一定基础后再进行系统评估 |
| 中级训练者 | ✅ | 可以通过书籍和软件掌握评估流程 |
| 高级训练者 | ✅ | 可以深入学习评估技术并应用于临床或教学 |

## 具体参数

| 参数 | 推荐值 | 范围 | 说明 |
|------|--------|------|------|
| 体态评估 | 骨盆侧倾、高低肩等 | - | 初步判断身体结构问题 |
| 动作模式评估 | 髋外展、屈髋等 | - | 通过动作测试判断肌肉代偿 |
| 呼吸模式评估 | 胸式呼吸、腹式呼吸等 | - | 评估呼吸模式对运动的影响 |
| 关节活动度评估 | 屈髋、屈膝、踝背伸等 | - | 判断关节功能是否受限 |
| 步态评估 | 正常与异常步态 | - | 综合分析全身运动模式 |
| 肌肉力量测试 | 臀中肌、腰方肌等 | - | 用于判断肌肉是否无力或紧张 |

## 禁忌症与注意事项

- ⚠️ 不要忽略任何评估环节，避免遗漏关键问题
- ❌ 评估需结合理论知识，否则难以准确判断问题根源

## 实践建议

1. 学习体态评估，使用《知识评估》《知识异常和肌肉骨骼功能失调》等书籍
2. 掌握动作模式评估，如髋外展测试，判断肌肉代偿情况
3. 使用muscle and motion软件辅助评估，提高效率与准确性
