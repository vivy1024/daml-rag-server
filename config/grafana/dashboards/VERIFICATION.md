## 常见问题排查

### 问题1: 仪表板不显示

**症状**: 在Grafana中找不到 "日志查询和分析" 仪表板

**排查步骤**:
1. 检查仪表板文件是否存在：
   ```bash
   ls -la daml-rag-server/config/grafana/dashboards/logs-query-analysis.json
   ```

2. 检查Grafana容器中的文件：
   ```bash
   docker exec fitness_grafana ls -la /etc/grafana/provisioning/dashboards/
   ```

3. 检查Grafana日志：
   ```bash
   docker logs fitness_grafana --tail 100 | grep -i "dashboard\|provisioning"
   ```

4. 重启Grafana容器：
   ```bash
   docker-compose restart grafana
   ```

### 问题2: 面板显示 "No data"

**症状**: 所有面板都显示 "No data"

**排查步骤**:
1. 检查Loki服务是否运行：
   ```bash
   docker ps | grep loki
   ```

2. 检查Promtail服务是否运行：
   ```bash
   docker ps | grep promtail
   ```

3. 检查Loki数据源配置：
   - 在Grafana中，进入 Configuration -> Data Sources
   - 找到 "Loki" 数据源
   - 点击 "Test" 按钮验证连接

4. 在Grafana Explore中手动查询：
   - 点击左侧菜单的 "Explore" 图标
   - 选择 "Loki" 数据源
   - 输入查询：`{job="daml-rag"}`
   - 点击 "Run query" 按钮

5. 检查日志采集：
   ```bash
   # 检查Promtail日志
   docker logs fitness_promtail --tail 50
   
   # 检查Loki日志
   docker logs fitness_loki --tail 50
   ```

### 问题3: 变量输入不生效

**症状**: 输入request_id或user_id后，面板没有更新

**排查步骤**:
1. 确认变量值格式正确
2. 在实时日志流中查看实际的字段值格式
3. 尝试使用部分匹配
4. 检查时间范围是否包含该数据

### 问题4: 日志显示不完整

**症状**: 日志内容被截断

**排查步骤**:
1. 点击日志条目展开查看完整内容
2. 调整面板的 `maxLines` 参数
3. 在Grafana Explore中查询完整日志
