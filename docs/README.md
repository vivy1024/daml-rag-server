## 📋 概述

欢迎来到DAML-RAG（Dynamic Adaptive Multi-Layer Retrieval-Augmented Generation）文档中心。本文档库采用模块化组织结构，按内容深度和功能模块分类，帮助您快速找到所需信息。

### 核心特性

- **三段式架构**：LLM决策 + 程序执行 + LLM综合
- **11步工作流程**：从用户档案预加载到交互记录的完整流程
- **三层检索**：Vector → Graph → Constraint，确保无幻觉
- **混合MCP架构**：17个Python内置工具 + 1个stdio用户档案服务
- **流式输出**：SSE实时推送工作流程状态和LLM生成内容
- **四层代码架构**：API层(16文件) + 应用层(66文件) + 框架层(86文件) + 工具层(4文件)
