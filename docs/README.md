## 概述

DAML-RAG（Dynamic Adaptive Multi-Layer Retrieval-Augmented Generation）系统文档。

### v3.0 架构定位

DAML-RAG v3.0 精简为 **MCP Server + 三层检索引擎**：
- 通过 stdio transport 被 YuzhenFork Agent 调用
- 提供 18 个 MCP 工具（10 个对外暴露）
- 三层检索：Qdrant 向量 + Neo4j 图 + 规则约束
- 健康检查 API

**已删除的模块**：`agent_v2/`, `skills/`, `workflow/`, `dag/`, `orchestration/`, `harness/`, `context/`
**新增模块**：`src/mcp_server.py`, `calibrated_fusion.py`, `graph_conv_rerank.py`, `query_reshaper.py`, `in_memory_hot_cache.py`, `structured_output.py`, `eval/`
