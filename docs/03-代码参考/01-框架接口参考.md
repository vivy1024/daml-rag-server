## 📋 概述

DAML-RAG框架采用实用化的接口设计，重点关注领域适配性和模块解耦。本文档介绍框架中实际实现的核心接口。

**接口文件位置**: `src/framework/interfaces/`

**实际接口分类**:
- **适配器接口**: IDomainAdapter, IQueryAdapter, IWorkflowAdapter
- **结果处理接口**: IResultProcessor
- **适配器注册管理**: AdapterRegistry

## 🔧 适配器接口体系

### IDomainAdapter - 领域适配器基础接口

**文件**: `src/framework/interfaces/base_adapter.py`

**作用**: 定义所有领域适配器必须实现的通用接口，确保框架层与应用层解耦。

```python
@dataclass
class AdapterContext:
    """适配器上下文"""
    user_id: Optional[str] = None
    user_profile: Optional[Dict[str, Any]] = None
    domain: str = "general"
    metadata: Dict[str, Any] = None

@dataclass
class AdapterResult:
    """适配器结果"""
    success: bool
    data: Any = None
    error: Optional[str] = None
    metadata: Dict[str, Any] = None

class IDomainAdapter(ABC):
    """领域适配器接口"""

    def __init__(self, domain: str):
        self.domain = domain
        self.is_initialized = False

    @abstractmethod
    async def initialize(self) -> bool:
        """初始化适配器"""
        pass

    @abstractmethod
    async def process_query(
        self,
        query: str,
        context: AdapterContext,
        **kwargs
    ) -> AdapterResult:
        """处理查询请求"""
        pass

    @abstractmethod
    async def get_supported_operations(self) -> List[str]:
        """获取支持的操作列表"""
        pass
```

**实际应用**:
- `FitnessAdapter`: 健身领域适配器
- `NutritionAdapter`: 营养领域适配器
- `RehabilitationAdapter`: 康复领域适配器

### IQueryAdapter - 查询适配器接口

**继承**: IDomainAdapter

**作用**: 专门用于处理查询请求的适配器

```python
class IQueryAdapter(IDomainAdapter):
    """查询适配器接口"""

    @abstractmethod
    async def query_vector(
        self,
        query_text: str,
        top_k: int = 10,
        filters: Optional[Dict[str, Any]] = None
    ) -> AdapterResult:
        """向量检索"""
        pass

    @abstractmethod
    async def query_graph(
        self,
        query_text: str,
        cypher: Optional[str] = None,
        filters: Optional[Dict[str, Any]] = None
    ) -> AdapterResult:
        """图检索"""
        pass

    @abstractmethod
    async def hybrid_query(
        self,
        query_text: str,
        top_k: int = 10,
        filters: Optional[Dict[str, Any]] = None
    ) -> AdapterResult:
        """混合检索（向量+图）"""
        pass
```

### IResultProcessor - 结果处理器接口

**文件**: `src/framework/interfaces/result_processor.py`

**作用**: 统一处理不同适配器的结果，实现格式标准化和质量控制

```python
class IResultProcessor(ABC):
    """结果处理器接口"""

    @abstractmethod
    async def process(
        self,
        raw_result: Any,
        processing_config: Dict[str, Any] = None
    ) -> ProcessedResult:
        """处理原始结果"""
        pass

    @abstractmethod
    async def validate_quality(
        self,
        processed_result: ProcessedResult
    ) -> QualityScore:
        """验证结果质量"""
        pass

    @abstractmethod
    async def enrich_context(
        self,
        result: ProcessedResult,
        context: Dict[str, Any]
    ) -> ProcessedResult:
        """丰富结果上下文"""
        pass
```

## 📋 适配器注册管理

### AdapterRegistry - 适配器注册表

**文件**: `src/framework/interfaces/base_adapter.py`

**作用**: 管理所有适配器的注册、实例化和生命周期

```python
class AdapterRegistry:
    """适配器注册表"""

    _adapters: Dict[str, type] = {}
    _instances: Dict[str, IDomainAdapter] = {}

    @classmethod
    def register(cls, domain: str, adapter_class: type):
        """注册适配器类"""
        cls._adapters[domain] = adapter_class

    @classmethod
    async def get_adapter(
        cls,
        domain: str,
        **kwargs
    ) -> Optional[IDomainAdapter]:
        """获取适配器实例（单例）"""
        if domain not in cls._instances:
            adapter_class = cls.get_adapter_class(domain)
            if adapter_class:
                adapter = adapter_class(domain, **kwargs)
                await adapter.initialize()
                cls._instances[domain] = adapter
        return cls._instances[domain]
```

## 🏗️ 接口设计原则

### 1. 领域分离
- **框架层**: 领域无关，定义通用接口
- **应用层**: 领域专用，实现具体逻辑

### 2. 上下文驱动
- `AdapterContext`: 统一的上下文传递机制
- `AdapterResult`: 标准化的结果格式

### 3. 异步优先
- 所有接口方法都是异步的
- 支持并发执行和资源优化

### 4. 容错设计
- 完整的错误处理机制
- 优雅的降级策略

## 🔗 实际应用示例

### 健身领域适配器实现

```python
from src.framework.interfaces.base_adapter import IDomainAdapter, AdapterContext, AdapterResult

class FitnessAdapter(IDomainAdapter):
    """健身领域适配器"""

    def __init__(self):
        super().__init__("fitness")
        self.exercise_db = None
        self.muscle_mapping = None

    async def initialize(self) -> bool:
        """初始化健身领域资源"""
        self.exercise_db = await self._load_exercise_database()
        self.muscle_mapping = await self._load_muscle_mapping()
        self.is_initialized = True
        return True

    async def process_query(
        self,
        query: str,
        context: AdapterContext,
        **kwargs
    ) -> AdapterResult:
        """处理健身查询"""
        try:
            # 基于用户档案和查询内容进行分析
            user_profile = context.user_profile
            analysis_result = await self._analyze_fitness_query(
                query, user_profile
            )

            return AdapterResult(
                success=True,
                data=analysis_result,
                metadata={
                    "processing_time": 0.12,
                    "data_sources": ["exercise_db", "muscle_mapping"],
                    "confidence": 0.94
                }
            )
        except Exception as e:
            return AdapterResult(
                success=False,
                error=str(e),
                metadata={"error_type": "processing_error"}
            )
```

### 适配器注册和使用

```python
# 注册适配器
AdapterRegistry.register("fitness", FitnessAdapter)

# 获取并使用适配器
fitness_adapter = await AdapterRegistry.get_adapter("fitness")

# 创建上下文
context = AdapterContext(
    user_id="user_123",
    user_profile={
        "age": 28,
        "gender": "male",
        "fitness_level": "intermediate",
        "goals": ["muscle_gain"]
    }
)

# 处理查询
result = await fitness_adapter.process_query(
    query="胸部训练计划",
    context=context
)
```
