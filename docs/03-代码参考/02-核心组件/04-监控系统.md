## 概述

性能监控系统提供全面的性能监控和统计功能，用于监控DAG执行、LLM调用、缓存命中率等关键指标。

**核心特性**：
1. DAG执行性能监控
2. LLM调用统计
3. 缓存命中率统计
4. 工具执行时间分析
5. 性能趋势分析
6. 优化建议生成

**对应需求**: Requirements 12.1-12.5

---

## 核心组件

### 1. PerformanceMonitor

主要的性能监控类，负责收集和分析所有性能指标。

```python
from src.applications.fitness.performance_monitor import (
    PerformanceMonitor,
    ToolExecutionMetrics,
    DAGExecutionMetrics,
    LLMCallMetrics,
    CacheMetrics
)

# 创建监控实例
monitor = PerformanceMonitor(max_history_size=1000)
```

### 2. 指标数据类

#### ToolExecutionMetrics - 工具执行指标

```python
@dataclass
class ToolExecutionMetrics:
    tool_name: str              # 工具名称
    execution_id: str           # 执行ID
    user_id: str                # 用户ID
    start_time: float           # 开始时间
    end_time: float             # 结束时间
    duration: float             # 执行时长
    success: bool               # 是否成功
    error_message: Optional[str]  # 错误信息
    cache_hit: bool             # 是否缓存命中
    retry_count: int            # 重试次数
    metadata: Dict[str, Any]    # 元数据
```

#### DAGExecutionMetrics - DAG执行指标

```python
@dataclass
class DAGExecutionMetrics:
    execution_id: str           # 执行ID
    template_id: str            # 模板ID
    template_name: str          # 模板名称
    user_id: str                # 用户ID
    start_time: float           # 开始时间
    end_time: float             # 结束时间
    total_duration: float       # 总执行时长
    tools_executed: int         # 执行工具数
    tools_succeeded: int        # 成功工具数
    tools_failed: int           # 失败工具数
    tools_cached: int           # 缓存工具数
    parallel_groups: int        # 并行组数
    max_parallel_degree: int    # 最大并行度
    cache_hit_rate: float       # 缓存命中率
    success_rate: float         # 成功率
    metadata: Dict[str, Any]    # 元数据
```

#### LLMCallMetrics - LLM调用指标

```python
@dataclass
class LLMCallMetrics:
    call_id: str                # 调用ID
    call_type: str              # 调用类型（decision/analysis）
    model_name: str             # 模型名称
    user_id: str                # 用户ID
    start_time: float           # 开始时间
    end_time: float             # 结束时间
    duration: float             # 执行时长
    prompt_tokens: int          # 提示词tokens
    completion_tokens: int      # 完成tokens
    total_tokens: int           # 总tokens
    success: bool               # 是否成功
    error_message: Optional[str]  # 错误信息
    confidence: float           # 置信度
    fallback_used: bool         # 是否使用降级
    metadata: Dict[str, Any]    # 元数据
```

## 统计指标说明

### 工具统计指标

- **total_calls**: 总调用次数
- **successful_calls**: 成功调用次数
- **failed_calls**: 失败调用次数
- **success_rate**: 成功率
- **cache_hits**: 缓存命中次数
- **cache_misses**: 缓存未命中次数
- **cache_hit_rate**: 缓存命中率
- **duration_stats**: 执行时长统计
  - min: 最小值
  - max: 最大值
  - avg: 平均值
  - median: 中位数
  - p95: 95百分位
  - p99: 99百分位

### DAG统计指标

- **total_executions**: 总执行次数
- **duration_stats**: 执行时长统计
- **success_rate**: 成功率统计
- **cache_hit_rate**: 缓存命中率统计
- **avg_tools_executed**: 平均执行工具数
- **avg_parallel_groups**: 平均并行组数

### LLM统计指标

- **total_calls**: 总调用次数
- **successful_calls**: 成功调用次数
- **failed_calls**: 失败调用次数
- **success_rate**: 成功率
- **fallback_calls**: 降级调用次数
- **fallback_rate**: 降级率
- **duration_stats**: 执行时长统计
- **token_stats**: Token统计
  - total_tokens: 总tokens
  - prompt_tokens: 提示词tokens
  - completion_tokens: 完成tokens
  - avg_tokens_per_call: 平均每次调用tokens

## 优化建议类型

### 1. slow_tool - 慢工具

**触发条件**: 平均执行时间 > 2.0秒

**建议**: 优化工具逻辑或增加缓存

### 2. low_cache_hit_rate - 低缓存命中率

**触发条件**: 缓存命中率 < 30% 且调用次数 > 20

**建议**: 增加缓存TTL或启用预加载

### 3. high_failure_rate - 高失败率

**触发条件**: 失败率 > 10%

**建议**: 检查错误日志并修复问题

### 4. slow_llm_call - LLM慢调用

**触发条件**: 平均执行时间 > 5.0秒

**建议**: 优化提示词或使用更快的模型

### 5. high_fallback_rate - 高降级率

**触发条件**: 降级率 > 20%

**建议**: 检查LLM服务稳定性

## 集成到三段式编排器

```python
from src.applications.fitness.performance_monitor import (
    get_performance_monitor,
    ToolExecutionMetrics,
    DAGExecutionMetrics,
    LLMCallMetrics
)

class ThreeStageOrchestrator:
    def __init__(self):
        self.performance_monitor = get_performance_monitor()
    
    async def execute(self, request):
        start_time = time.time()
        
        # ... 执行逻辑 ...
        
        # 记录DAG执行指标
        dag_metrics = DAGExecutionMetrics(
            execution_id=execution_id,
            template_id=template_id,
            template_name=template_name,
            user_id=request.user_id,
            start_time=start_time,
            end_time=time.time(),
            total_duration=time.time() - start_time,
            tools_executed=tools_executed,
            tools_succeeded=tools_succeeded,
            tools_failed=tools_failed,
            tools_cached=tools_cached,
            parallel_groups=parallel_groups,
            max_parallel_degree=max_parallel_degree,
            cache_hit_rate=cache_hit_rate,
            success_rate=success_rate
        )
        self.performance_monitor.record_dag_execution(dag_metrics)
```

## 最佳实践

### 1. 定期导出指标

```python
# 每小时导出一次指标
import schedule

def export_hourly_metrics():
    monitor = get_performance_monitor()
    metrics = monitor.export_metrics(format="json", time_window_seconds=3600)
    
    # 保存到文件或发送到监控系统
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    with open(f"metrics_{timestamp}.json", "w") as f:
        f.write(metrics)

schedule.every().hour.do(export_hourly_metrics)
```

### 2. 监控关键指标

```python
# 设置告警阈值
def check_performance_alerts():
    monitor = get_performance_monitor()
    snapshot = monitor.get_performance_snapshot(time_window_seconds=300)
    
    # 检查缓存命中率
    if snapshot.cache_hit_rate < 0.5:
        logger.warning(f"⚠️ 缓存命中率过低: {snapshot.cache_hit_rate:.1%}")
    
    # 检查成功率
    if snapshot.success_rate < 0.9:
        logger.warning(f"⚠️ 成功率过低: {snapshot.success_rate:.1%}")
    
    # 检查平均执行时间
    if snapshot.avg_dag_duration > 10.0:
        logger.warning(f"⚠️ DAG执行时间过长: {snapshot.avg_dag_duration:.2f}s")
```

### 3. 定期清理历史数据

```python
# 每天清理一次旧数据
def cleanup_old_metrics():
    monitor = get_performance_monitor()
    
    # 导出完整数据
    full_metrics = monitor.export_metrics(format="json")
    
    # 保存到长期存储
    save_to_long_term_storage(full_metrics)

schedule.every().day.at("00:00").do(cleanup_old_metrics)
```

## 故障排查

### 问题1: 统计数据不准确

**原因**: 时间窗口设置不当

**解决**: 使用合适的时间窗口参数

```python
# 使用最近1小时的数据
stats = monitor.get_tool_statistics(time_window_seconds=3600)
```

### 问题2: 内存占用过高

**原因**: 历史记录过多

**解决**: 减小max_history_size或定期清理

```python
# 创建时设置较小的历史大小
monitor = PerformanceMonitor(max_history_size=500)

# 或定期重置
monitor.reset_statistics()
```
