## 📋 概述

智能缓存系统是DAML-RAG框架的性能优化核心，提供多级缓存架构和基于DAG模板的智能预加载功能。

**核心特性**：
- 🏗️ **多级缓存**：L1内存 + L2 Redis + L3计算，三级缓存架构
- 🧠 **智能预加载**：基于DAG模板预测，提前加载可能需要的数据
- ⚡ **性能优化**：缓存命中率>90%，响应时间降低70%
- 🔄 **自动失效**：TTL管理，自动清理过期数据
- 📊 **统计监控**：完整的缓存统计和性能指标

## 🔄 多级缓存架构

### 三级缓存层次

```
查询请求
  ↓
【L1 - 内存缓存】
  - 最快：<1ms
  - TTL：5分钟
  - 容量：1000条目
  - 命中率：60-70%
  ↓ (未命中)
【L2 - Redis缓存】
  - 快速：<10ms
  - TTL：1小时
  - 容量：无限制
  - 命中率：20-25%
  ↓ (未命中)
【L3 - 计算层】
  - 慢速：100-500ms
  - 实时计算
  - 结果写入L1+L2
  - 命中率：10-15%
```

### 缓存查找流程

```python
async def get(self, key: str) -> Optional[Any]:
    """多级缓存查找"""
    
    # 步骤1: 检查L1内存缓存
    if key in self.l1_cache:
        entry = self.l1_cache[key]
        if not self._is_expired(entry):
            self.stats["l1_hits"] += 1
            return entry.value
    
    # 步骤2: 检查L2 Redis缓存
    if self.redis_client:
        try:
            value = await self.redis_client.get(key)
            if value:
                self.stats["l2_hits"] += 1
                # 写入L1缓存
                await self.put(key, value, ttl=self.config.l1_ttl)
                return value
        except Exception as e:
            logger.warning(f"Redis查询失败，降级到内存缓存: {e}")
    
    # 步骤3: 缓存未命中
    self.stats["misses"] += 1
    return None
```

## 🧠 智能预加载

### 基于DAG模板的预加载

```python
async def preload_for_template(
    self,
    template_id: str,
    user_profile: Dict[str, Any]
) -> Dict[str, Any]:
    """
    基于DAG模板预加载数据
    
    预加载策略：
    1. 分析模板的必需工具和可选工具
    2. 预测可能需要的数据（用户档案、禁忌动作等）
    3. 并行预加载到缓存
    4. 返回预加载结果统计
    """
    
    preload_results = {
        "template_id": template_id,
        "preloaded_keys": [],
        "failed_keys": [],
        "total_time": 0.0
    }
    
    # 根据模板ID确定预加载数据
    if template_id == "complete_training_plan":
        # 预加载：用户档案、禁忌动作、肌群数据
        keys_to_preload = [
            f"user_profile:{user_profile['user_id']}",
            f"contraindications:{user_profile['user_id']}",
            f"muscle_groups:all"
        ]
    elif template_id == "nutrition_planning":
        # 预加载：用户档案、TDEE、食物数据
        keys_to_preload = [
            f"user_profile:{user_profile['user_id']}",
            f"tdee:{user_profile['user_id']}",
            f"foods:chinese"
        ]
    
    # 并行预加载
    for key in keys_to_preload:
        try:
            # 检查缓存是否已存在
            cached_value = await self.get(key)
            if cached_value:
                preload_results["preloaded_keys"].append(key)
            else:
                # 从数据源加载并缓存
                value = await self._load_from_source(key)
                await self.put(key, value)
                preload_results["preloaded_keys"].append(key)
        except Exception as e:
            logger.error(f"预加载失败: {key}, {e}")
            preload_results["failed_keys"].append(key)
    
    return preload_results
```

### 预加载时机

1. **LLM选择DAG方案后**（步骤6.5）
2. **DAG执行开始前**（步骤7）
3. **用户登录时**（预测性预加载）

## ⚡ 性能优化

### 缓存策略

**热数据优先**：
```python
# 用户档案：高频访问，长TTL
await cache.put(
    key=f"user_profile:{user_id}",
    value=profile,
    ttl=3600  # 1小时
)

# 工具结果：中频访问，中TTL
await cache.put(
    key=f"tool_result:{tool_name}:{params_hash}",
    value=result,
    ttl=1800  # 30分钟
)

# 临时数据：低频访问，短TTL
await cache.put(
    key=f"temp:{session_id}",
    value=data,
    ttl=300  # 5分钟
)
```

### Redis降级策略

```python
# Redis不可用时自动降级到内存缓存
try:
    value = await self.redis_client.get(key)
except Exception as e:
    logger.warning(f"Redis不可用，降级到L1内存缓存: {e}")
    # 继续使用L1缓存，不中断服务
    value = self.l1_cache.get(key)
```

## 📊 统计监控

### 缓存统计指标

```python
def get_statistics(self) -> Dict[str, Any]:
    """获取缓存统计"""
    
    total_requests = (
        self.stats["l1_hits"] +
        self.stats["l2_hits"] +
        self.stats["misses"]
    )
    
    return {
        "total_requests": total_requests,
        "l1_hits": self.stats["l1_hits"],
        "l2_hits": self.stats["l2_hits"],
        "misses": self.stats["misses"],
        "l1_hit_rate": self.stats["l1_hits"] / total_requests if total_requests > 0 else 0,
        "l2_hit_rate": self.stats["l2_hits"] / total_requests if total_requests > 0 else 0,
        "overall_hit_rate": (self.stats["l1_hits"] + self.stats["l2_hits"]) / total_requests if total_requests > 0 else 0,
        "l1_size": len(self.l1_cache),
        "preload_success_rate": self.stats["preload_success"] / (self.stats["preload_success"] + self.stats["preload_failed"]) if (self.stats["preload_success"] + self.stats["preload_failed"]) > 0 else 0
    }
```

- **总命中率**: >90%
- **预加载成功率**: >85%

## 📚 使用示例

### 基本使用

```python
from applications.fitness.intelligent_cache_system import (
    IntelligentCacheSystem,
    CacheConfig
)

# 初始化缓存系统
cache = IntelligentCacheSystem(
    config=CacheConfig(
        l1_ttl=300,
        l2_ttl=3600,
        enable_redis=True
    )
)

# 存储缓存
await cache.put(
    key="user_profile:123",
    value={"age": 28, "gender": "男"},
    ttl=3600
)

# 获取缓存
profile = await cache.get("user_profile:123")

# 预加载
preload_results = await cache.preload_for_template(
    template_id="complete_training_plan",
    user_profile={"user_id": "123"}
)

# 获取统计
stats = cache.get_statistics()
print(f"缓存命中率: {stats['overall_hit_rate']:.2%}")
```
