# 12 - 枚举映射说明

> 更新日期：2026-02-24 | 关联：cross-stack-enum-unification spec

## 当前状态（v1.4.0 三端枚举统一后）

### 已完成的统一

| 枚举 | 统一前 | 统一后 | 权威来源 |
|------|--------|--------|---------|
| MembershipTier | AI服务用 `paid/vip`，后端用 `warmheart/energy` | 三端统一 `free/warmheart/energy` | MySQL `memberships.slug` |
| DifficultyLevel | 后端 import 缺 `novice` | 三端统一 `novice/beginner/intermediate/advanced` | Neo4j TrainingLevel |
| TrainingGoal（前端/后端） | 前端/后端用 `lose_weight/gain_muscle` | 前端/后端改为 `hypertrophy/fat_loss/strength/endurance/body_shaping/general_fitness` | Neo4j TrainingGoal |
| UserProfile 字段名 | AI服务用 `strength_levels/health_profile` | 三端统一 `strength_data/health_status` | 后端 InternalUserController |

### 仍保留的适配器

`task_executor.py` 的 `_GOAL_NORMALIZE` 映射仍然保留，因为 MySQL `user_profiles.fitness_goals.primary_goal` 中可能存在旧的中文值或旧英文值（`muscle_gain`/`weight_loss`）。待 Batch 4 数据迁移完成后可移除。

```python
_GOAL_NORMALIZE = {
    "weight_loss": "fat_loss",
    "muscle_gain": "hypertrophy",
}
```

### 保留映射清单（待数据迁移后清理）

| `context/profile_injector.py` | 中文目标映射 | MySQL 旧数据可能存中文值 |

| `services/training_goal_recommender.py` | 兼容判断 | 同时兼容新旧值 |

## 向量检索映射（不可删除）

以下映射用于将英文枚举转换为中文查询文本，供 Qdrant 向量检索使用（GTE-Large-zh 模型需要中文输入）：

| 文件 | 映射 | 用途 |
|------|------|------|
| `mcp_tools/exercise/intelligent_exercise_selector.py` | `difficulty_map`, `goal_map` | 枚举→中文，构建向量检索查询文本 |
| `mcp_tools/exercise/intelligent_exercise_selector.py` | `equipment_mapper` | 中英文器械名双向匹配 |

## 数据流（统一后）

```
MySQL user_profiles
  │ fitness_goals.primary_goal = "增肌" 或 "hypertrophy"（待迁移统一为英文）
  ▼
profile_injector（中文→英文映射，待迁移后移除）
  ▼
task_executor._get_primary_goal()
  │ _GOAL_NORMALIZE: "muscle_gain" → "hypertrophy"（待迁移后移除）
  ▼
MCP 营养工具 (Pydantic Literal 验证)
  │ 接受: "hypertrophy" | "fat_loss" | "maintenance" | "recomp"
  ▼
业务逻辑
```
