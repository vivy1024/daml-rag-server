## 🎯 两大核心功能

### 1. CONTRAINDICATED_FOR关系 - 禁忌症管理

**关注点**: ❌ 什么不能做

**数据结构**:
```cypher
(:Exercise)-[:CONTRAINDICATED_FOR {
    severity: "absolute/relative/caution",
    reason: "生物力学原因"
}]->(:InjuryType)
```

**数据量**: 3,726个禁忌关系，覆盖17个损伤类型

**使用场景**: 用户有损伤时，查询哪些动作是禁忌的

---

### 2. RehabilitationPhase + REHAB_PROGRESSION - 康复路径管理

**关注点**: ✅ 应该怎么做

**数据结构**:
```cypher
(:RehabilitationPhase {name: "acute/subacute/recovery"})
(:Exercise)-[:REHAB_PROGRESSION {
    from_phase: "acute",
    to_phase: "subacute",
    progression_criteria: "标准",
    estimated_weeks: 2
}]->(:Exercise)
```

**数据量**: 3个康复阶段，5个渐进关系

**使用场景**: 指导用户按照康复阶段逐步恢复训练

---

## 🔄 互补关系

两者是完美互补的：

1. **CONTRAINDICATED_FOR** = 安全边界（红线）
2. **REHAB_PROGRESSION** = 康复路径（绿灯）

**综合使用流程**:
```
用户输入损伤
  ↓
1. 查询禁忌动作（CONTRAINDICATED_FOR）→ 排除危险动作
  ↓
2. 判断康复阶段（RehabilitationPhase）→ 确定当前阶段
  ↓
3. 推荐康复路径（REHAB_PROGRESSION）→ 给出渐进方案
  ↓
综合建议：既安全又有指导性
```

## 📊 两个severity的区别

### InjuryType.severity_level - 损伤本身的严重程度

- **位置**: InjuryType节点的属性
- **取值**: mild（轻度）/ moderate（中度）/ severe（重度）
- **含义**: 描述损伤类型本身的医学严重程度
- **用途**: 评估损伤的整体风险，影响康复周期

### CONTRAINDICATED_FOR.severity - 禁忌关系的严重程度

- **位置**: CONTRAINDICATED_FOR关系的属性
- **取值**: absolute（绝对禁忌）/ relative（相对禁忌）/ caution（谨慎使用）
- **含义**: 描述某个动作对某个损伤的禁忌程度
- **用途**: 决定具体动作是否可以做

### 关系说明

- **相关但独立**: 两者是不同维度的评估
- **有影响但不决定**: 重度损伤不代表所有动作都绝对禁忌
- **互补使用**: 结合两者可以做出更精准的训练建议

**综合评估公式**:
```
训练建议 = InjuryType.severity_level + CONTRAINDICATED_FOR.severity

示例：
- 重度损伤 + 绝对禁忌 = ❌ 完全禁止
- 重度损伤 + 相对禁忌 = ❌ 强烈不建议
- 中度损伤 + 绝对禁忌 = ❌ 完全禁止
- 中度损伤 + 相对禁忌 = ⚠️ 谨慎进行（需指导）
- 轻度损伤 + 绝对禁忌 = ❌ 避免
- 轻度损伤 + 相对禁忌 = ⚠️ 可以尝试（注意反应）
```

## 💡 实际应用示例

### 场景：膝盖受伤用户想恢复深蹲训练

```
1. 禁忌症检查
   查询：膝盖受伤 → 禁忌动作
   结果：❌ 杠铃深蹲（绝对禁忌）
         ❌ 跳跃动作（绝对禁忌）
         ⚠️ 弓步蹲（相对禁忌）

2. 康复阶段判断
   用户当前：亚急性期（受伤后2周）
   目标：恢复期（4-6周后）

3. 康复路径推荐
   Week 1-2: 靠墙静蹲（急性期）
   Week 3-4: 徒手深蹲（亚急性期）← 当前阶段
   Week 5-8: 杠铃深蹲（恢复期）

4. 综合建议
   ✅ 当前可以做：徒手深蹲
   ❌ 当前不能做：杠铃深蹲
   ⚠️ 注意事项：避免膝盖屈曲>90度
```
