## 📋 概述

本目录包含DAML-RAG系统的代码实现参考文档，回答"怎么实现"的问题。文档按功能模块组织，涵盖工作流程步骤、核心组件、MCP工具实现、DAG模板实现和流式输出五大模块。

### 代码规模

- **总文件数**：172个Python文件
- **框架层**：86个文件（监控、编排、存储等）
- **应用层**：66个文件（MCP工具、服务层、工作流等）
- **API层**：16个文件（路由、配置、中间件等）
- **MCP工具**：17个Python内置工具 + 1个stdio服务

## 🔗 代码组织结构（v6.0）

```
src/
├── api/                         # API层（16文件）
│   ├── routes/                 # API路由
│   ├── config/                 # 配置文件
│   ├── middleware/             # 中间件
│   └── utils/                  # 工具类
│
├── applications/                # 应用层（66文件）
│   └── fitness/
│       ├── mcp_tools/          # 18个Python内置MCP工具
│       ├── services/           # 16个服务层组件
│       ├── workflow/           # 工作流执行器
│       ├── dag/                # DAG编排器
│       └── parameters/         # 6个参数系统组件
│
├── framework/                   # 框架层（86文件）
│   ├── core/                   # 核心接口和基类
│   ├── llm/                    # LLM客户端
│   ├── cache/                  # 缓存系统
│   ├── monitoring/             # 监控系统（11文件）
│   ├── orchestration/          # DAG编排器（12文件）
│   ├── storage/                # 存储层（12文件）
│   └── clients/                # 客户端封装
│
└── tools/                       # 工具层（4文件）
```

**代码路径说明**：
- **框架层代码**：`src/framework/` - 参考 [02-核心组件](./02-核心组件/)
- **MCP工具代码**：`src/applications/fitness/mcp_tools/` - 参考 [03-MCP工具实现](./03-MCP工具实现/)
- **DAG模板代码**：`src/applications/fitness/dag_templates/` - 参考 [04-DAG模板实现](./04-DAG模板实现/)
- **流式输出代码**：`src/api/routes/chat.py` - 参考 [05-流式输出](./05-流式输出/)
