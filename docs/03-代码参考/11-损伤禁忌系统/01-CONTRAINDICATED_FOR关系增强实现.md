## 🎯 严重程度分级

### 绝对禁忌 (Absolute Contraindication) 🚫

**定义**: 任何情况下都不应进行的动作

**特征**:
- 有明确的医学证据支持
- 会直接加重损伤
- 可能导致二次损伤

**示例**:
- 肩袖损伤患者做过头推举
- 腰椎间盘突出患者做硬拉
- 髌骨软化症患者做深蹲

### 相对禁忌 (Relative Contraindication) ⚠️

**定义**: 在特定条件下可以进行的动作

**特征**:
- 需要专业指导和监督
- 需要适当的技术和负荷控制
- 取决于损伤严重程度和康复阶段

**示例**:
- 恢复期肩袖损伤患者做轻负荷肩推
- 轻度下背部疼痛患者做浅蹲
- 膝盖轻微不适患者做半程弓步蹲

### 谨慎使用 (Use with Caution) 💡

**定义**: 可以进行但需要特别注意的动作

**特征**:
- 需要适当的热身和准备
- 需要密切监控身体反应
- 建议降低负荷和强度

**示例**:
- 老年人做跳跃动作
- 高血压患者做大重量训练
- 孕妇做平衡训练

## 🔬 生物力学原理

### 1. 肩袖损伤

**禁忌原理**:
- 肩关节外展>90度时，肩峰下空间压力增大
- 过头动作会压迫肩袖肌群
- 内旋受限时强行训练会撕裂肌腱

**关键动作特征**:
- 肩关节外展超过90度
- 过头推举
- 重负荷肩部训练

### 2. 髌骨软化症

**禁忌原理**:
- 膝关节屈曲时，髌骨与股骨接触面积减小
- 屈膝90度时压力达到体重的3-4倍
- 深蹲时压力可达体重的7-8倍

**关键动作特征**:
- 膝关节屈曲超过90度
- 跳跃和冲击性动作
- 长时间膝关节屈曲姿势

### 3. 腰椎间盘突出

**禁忌原理**:
- 脊柱前屈时，椎间盘前部受压，后部纤维环张力增大
- 旋转+前屈产生剪切力
- 轴向压缩增加椎间盘内压

**关键动作特征**:
- 脊柱前屈动作
- 脊柱旋转+前屈组合
- 轴向压缩脊柱的动作

## 📊 数据库结构

### 关系属性

```cypher
(Exercise)-[r:CONTRAINDICATED_FOR]->(InjuryType)

关系属性:
- severity: 严重程度 (absolute/relative/caution)
- reason: 禁忌原因（生物力学解释）
- created_at: 创建时间
- source: 数据来源 (expert_discussion_v2)
```

### 查询示例

```cypher
// 查询肩袖损伤的绝对禁忌动作
MATCH (e:Exercise)-[r:CONTRAINDICATED_FOR {severity: 'absolute'}]->(i:InjuryType {name: '肩袖损伤'})
RETURN e.name_zh, r.reason

// 查询某个动作的所有禁忌症
MATCH (e:Exercise {name_zh: '杠铃深蹲'})-[r:CONTRAINDICATED_FOR]->(i:InjuryType)
RETURN i.name, r.severity, r.reason

// 统计各损伤类型的禁忌动作数量
MATCH (e:Exercise)-[r:CONTRAINDICATED_FOR]->(i:InjuryType)
RETURN i.name, r.severity, count(e) as count
ORDER BY count DESC
```

## 📝 使用建议

### 对于开发者

1. **查询禁忌症时考虑严重程度**:
   ```python
   # 优先显示绝对禁忌
   absolute_contraindications = query_contraindications(severity='absolute')
   # 然后显示相对禁忌
   relative_contraindications = query_contraindications(severity='relative')
   ```

2. **提供替代动作建议**:
   - 当动作被禁忌时，自动推荐安全的替代动作
   - 使用exercise_alternative_finder工具

3. **个性化评估**:
   - 根据用户的康复阶段调整禁忌程度
   - 急性期：严格遵守绝对禁忌
   - 恢复期：可以尝试相对禁忌（在指导下）

### 对于用户

1. **绝对禁忌**: 完全避免，寻找替代动作
2. **相对禁忌**: 咨询专业人员后决定
3. **谨慎使用**: 降低负荷，密切监控身体反应
