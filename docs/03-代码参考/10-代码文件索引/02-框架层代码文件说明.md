## 概览

框架层位于 `src/framework/`，提供**领域无关**的通用组件，可被任何垂直领域复用。

### 框架层设计原则

1. **领域无关**: 所有组件不包含特定领域的硬编码数据
2. **可复用**: 可被健身、医疗、教育等任何垂直领域复用
3. **高性能**: 连接池、多级缓存、并发优化
4. **可扩展**: 接口清晰，易于扩展新功能

```
src/framework/
├── clients/          # 客户端（MCP、HTTP、LLM、Neo4j、Qdrant等）
├── retrieval/        # 检索引擎（三层检索、Few-Shot）
├── orchestration/    # 编排器（DAG编排、参数转换、工具调用）
├── storage/          # 存储（统一缓存、元数据、连接池）
├── models/           # 模型（LLM选择、复杂度分类、模型缓存）
├── adapters/         # 适配器（数据转换、领域适配）
├── processors/       # 处理器（结果处理）
├── interfaces/       # 接口定义（适配器接口、处理器接口）
├── core/             # 核心工具（框架初始化、查询对象）
├── monitoring/       # 监控（性能监控、指标收集、流式监控）
├── mcp/              # MCP工具层（缓存管理、错误处理）
├── dag/              # DAG编排层（条件分支、重试处理）
├── auth/             # 认证层（会员控制、权限检查）
├── config/           # 配置层（LLM配置、性能配置）
├── skills/           # 技能层（技能管理、技能执行）
├── tools/            # 工具注册层（工具注册表）
├── utils/            # 工具层（配置工具）
└── base/             # 基础层（可执行接口）
```

### 1. `mcp_client_v2.py` - MCP客户端V2 ⭐⭐⭐

**功能**: 管理MCP服务器连接，提供统一的工具调用接口

**核心类**:
```python
class MCPClientPool:
    """MCP客户端池 - 管理多个MCP服务器连接"""
    
    def __init__(self):
        self.clients = {}           # 已连接的客户端
        self.registry = {}          # 服务器注册表
        self.connection_pool = {}   # 连接池
    
    def register(self, server_name: str, config: Dict[str, Any]):
        """注册MCP服务器"""
        
    async def connect(self, server_name: str):
        """连接到MCP服务器"""
        
    async def call_tool(
        self, 
        server_name: str, 
        tool_name: str, 
        arguments: Dict[str, Any]
    ) -> Dict[str, Any]:
        """调用MCP工具"""
        
    async def disconnect(self, server_name: str):
        """断开连接"""
```

**特点**:
- ✅ 连接池管理（复用连接）
- ✅ 自动重连（连接失败时）
- ✅ 错误处理（超时、重试）
- ✅ 性能监控（调用统计）

**使用示例**:
```python
# 初始化客户端池
pool = MCPClientPool()

# 注册MCP服务器
pool.register("user-profile-mcp", {
    "command": "node",
    "args": ["dist/index.js"],
    "env": {"PORT": "3001"}
})

# 调用工具
result = await pool.call_tool(
    server_name="user-profile-mcp",
    tool_name="get_user_profile",
    arguments={"user_id": "123"}
)
```

**调用链路**:
```
应用层 → MCPClientPool.call_tool() → MCP服务器 → 返回结果
```

### 1. `true_three_layer_engine.py` - 三层检索引擎 ⭐⭐⭐

**功能**: 实现Vector → Graph → Constraint的三层检索架构

**核心类**:
```python
class TrueThreeLayerEngine:
    """真正的三层检索引擎"""
    
    async def query(
        self,
        query_text: str,
        user_profile: Dict[str, Any],
        top_k: int = 20
    ) -> Dict[str, Any]:
        """
        执行三层检索
        
        流程:
        1. Layer 1: 向量语义检索（Qdrant + GTE-Large-zh）
        2. Layer 2: 图谱关系推理（Neo4j）
        3. Layer 3: 业务规则约束（Python逻辑）
        
        Returns:
            {
                "results": [...],
                "layer1_count": 20,
                "layer2_count": 15,
                "layer3_count": 10,
                "confidence": 0.95
            }
        """
```

**Layer 1: 向量检索**
```python
async def _execute_layer1_vector_retrieval(
    self,
    query_text: str,
    top_k: int
) -> List[Dict]:
    """
    使用GTE-Large-zh向量化查询，在Qdrant中检索
    
    返回: Top-K个语义相似的候选结果
    """
```

**Layer 2: 图谱推理**
```python
async def _execute_layer2_graph_query(
    self,
    candidates: List[Dict],
    user_profile: Dict[str, Any]
) -> List[Dict]:
    """
    使用Neo4j进行关系推理
    
    过滤:
    - 禁忌动作（CONTRAINDICATED_FOR关系）
    - 器械要求（REQUIRES关系）
    - 目标肌肉（TARGETS_PRIMARY/SECONDARY关系）
    """
```

**Layer 3: 业务规则**
```python
def _execute_layer3_business_rules_validation(
    self,
    candidates: List[Dict],
    user_profile: Dict[str, Any]
) -> List[Dict]:
    """
    应用业务规则约束
    
    规则:
    1. 训练水平匹配（difficulty vs fitness_level）
    2. 安全性验证（contraindications vs medical_conditions）
    3. 器械可用性（equipment vs available_equipment）
    4. 训练容量评估（MEV/MAV/MRV）
    """
```

**调用链路**:
```
用户查询
  ↓
Layer 1: Qdrant向量检索（召回Top 20）
  ↓
Layer 2: Neo4j图谱过滤（过滤到15个）
  ↓
Layer 3: 业务规则验证（最终10个）
  ↓
返回结果
```

### 1. `unified_cache.py` - 统一缓存模块 ⭐⭐⭐（新）

**功能**: 提供统一的多级缓存接口，支持L1（内存）+ L2（Redis）架构

**核心类**:
```python
class UnifiedCache:
    """统一缓存模块 - 简化版多级缓存"""
    
    def __init__(self):
        self.l1_cache = {}  # 内存缓存（LRU）
        self.l2_cache = RedisClient()  # Redis缓存
        self.cache_stats = CacheStats()  # 缓存统计
    
    async def get(
        self,
        key: str,
        cache_type: str = "default"
    ) -> Optional[Dict]:
        """
        获取缓存（L1 → L2 → 源）
        
        Args:
            key: 缓存键
            cache_type: 缓存类型（user_profile/membership/tool_result）
            
        Returns:
            缓存值或None
        """
        
    async def set(
        self,
        key: str,
        value: Dict,
        ttl: int = 3600,
        cache_type: str = "default"
    ):
        """设置缓存（同时写入L1和L2）"""
        
    async def delete(self, key: str):
        """删除缓存"""
        
    def get_stats(self) -> Dict[str, Any]:
        """获取缓存统计"""
```

**缓存策略**:
- L1（内存）: 5分钟TTL，LRU淘汰，最快
- L2（Redis）: 1小时TTL，持久化
- 自动降级: L2不可用时仅使用L1

**特点**:
- ✅ 简化架构（移除过度设计）
- ✅ 统一接口（所有缓存类型）
- ✅ 高性能（L1内存缓存）
- ✅ 高可用（L2 Redis持久化）
- ✅ 监控友好（缓存统计）

**用于**: 步骤1（用户档案）、步骤3（会员权限）、步骤9（工具结果）

```python
class QueryComplexityClassifier:
    """查询复杂度分类器 - GTE-Large-zh"""
    
    def __init__(self):
        self.model = SentenceTransformer("BAAI/bge-m3")
        self.complex_examples = self._load_complex_examples()
    
    def classify_complexity(
        self,
        query: str
    ) -> Tuple[bool, float, str]:
        """
        分类查询复杂度
        
        Args:
            query: 用户查询
            
        Returns:
            (is_complex, similarity, reason)
            - is_complex: True（复杂）/ False（简单）
            - similarity: 与历史案例的相似度（0.0-1.0）
            - reason: 分类理由
        """
```

**分类逻辑**:
```python
# 1. 向量化查询
query_vector = self.model.encode(query)

# 2. 计算与复杂案例的相似度
similarities = cosine_similarity(query_vector, self.complex_examples)
max_similarity = max(similarities)

# 3. 判断复杂度
if max_similarity >= 0.7:
    return True, max_similarity, "高相似度，复杂查询"
elif max_similarity < 0.5:
    return False, max_similarity, "低相似度，简单查询"
else:
    return None, max_similarity, "中等相似度，需检查Few-Shot"
```
