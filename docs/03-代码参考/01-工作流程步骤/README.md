## 模块说明

本模块包含DAML-RAG工作流程11个步骤的详细代码实现文档，按执行顺序组织。这些文档详细说明了每个步骤的代码实现细节、数据流转和关键逻辑。

### 三段式架构

工作流程分为三个阶段：

**阶段1：LLM决策（步骤1-6.5）**
- 步骤1: 用户档案预加载
- 步骤2: 会话记录存储
- 步骤3: 会员权限检查
- 步骤4: BGE复杂度分类
- 步骤5: 智能模型选择
- 步骤6: Few-Shot检索
- 步骤6.5: LLM选择DAG方案

**阶段2：程序执行（步骤7-9）**
- 步骤7: DAG编排器
- 步骤8: 三层检索
- 步骤9: 工具结果汇总

**阶段3：LLM综合（步骤10-11）**
- 步骤10: LLM深度分析
- 步骤11: 交互记录
