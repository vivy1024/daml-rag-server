**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

## 概述

步骤2负责两件事：**生成/确认会话ID** 和 **加载对话历史**。从 `ConversationMemory` 加载用户的历史对话记录（Redis → 内存 → 后端三级存储），格式化为 LLM 可用格式写入 `WorkflowState`，供后续步骤（Few-Shot 检索、LLM 分析）使用。

### 在工作流中的位置

```
步骤1: 预加载用户档案
  ↓
步骤2: 会话记录存储 ⭐ ← 当前
  ↓  输出 session_id, conversation_history, conversation_topic_id → 写入 WorkflowState
步骤3: 会员权限检查
```

## 函数签名

```python
async def node_store_session(
    state: WorkflowState,
    conversation_memory=None,
) -> StateUpdate:
```

### 参数说明

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `state` | `WorkflowState` | ✅ | 当前工作流状态，包含 `request_id`、`user_id`、`session_id`、`conversation_topic_id` |
| `conversation_memory` | `ConversationMemory \| None` | ❌ | 对话记忆管理器，负责历史加载和话题切换 |

### 返回值

```python
StateUpdate(updates={
    "session_id": str,                    # 会话ID（已有则保留，无则生成）
    "conversation_history": List[Dict],   # 格式化后的对话历史
    "conversation_topic_id": str | None,  # 当前活跃话题ID
})
```

---

## 执行逻辑

### 1. 会话ID处理

```python
request_id = state.get("request_id", "unknown")
user_id = state.get("user_id", "anonymous")
session_id = state.get("session_id")
topic_id = state.get("conversation_topic_id")

# state 中已有 session_id → 保留
# 没有 → 自动生成
if not session_id:
    session_id = f"session_{user_id}_{int(time.time())}"
```

### 2. 加载对话历史

仅在 `conversation_memory` 可用且用户非匿名时执行：

```python
conversation_history = []
active_topic_id = topic_id

if conversation_memory and user_id != "anonymous":
    # 如果指定了 topic_id，切换到该话题
    if topic_id:
        await conversation_memory.switch_topic(
            user_id, topic_id, create_if_not_exists=True
        )
    else:
        # 未指定则获取当前活跃话题
        active_topic_id = conversation_memory.get_active_topic_id(user_id)

    # 加载历史消息
    messages = await conversation_memory.get_history(
        user_id=user_id,
        topic_id=active_topic_id,
    )

    # 格式化为 LLM 可用格式
    if messages:
        conversation_history = conversation_memory.format_history_for_llm(messages)
```

### 话题切换逻辑

| 场景 | 行为 |
|------|------|
| `topic_id` 已指定 | 调用 `switch_topic()` 切换到指定话题，不存在则自动创建 |
| `topic_id` 未指定 | 调用 `get_active_topic_id()` 获取当前活跃话题 |
| 用户为匿名 | 跳过历史加载，返回空列表 |

---

## 错误处理

本节点采用**全容错**设计：

| 场景 | 处理方式 | 返回值 |
|------|---------|--------|
| `conversation_memory` 为 None | 跳过历史加载 | `conversation_history=[]` |
| 用户为匿名 | 跳过历史加载 | `conversation_history=[]` |
| 历史加载异常 | `except Exception` 捕获，记录 warning | `conversation_history=[]` |

所有失败场景下工作流继续执行，后续步骤需处理空历史的情况。

---

## 与后续步骤的数据流

### 输出到步骤6（Few-Shot 检索）

`state["conversation_history"]` 提供对话上下文，用于 Few-Shot 示例的相关性匹配。

### 输出到步骤10（LLM 深度分析）

`state["conversation_history"]` 作为 LLM 提示词的一部分，让模型理解对话上下文。

### 输出到步骤11（交互记录）

`state["session_id"]` 和 `state["conversation_topic_id"]` 用于将本次交互记录关联到正确的会话和话题。
