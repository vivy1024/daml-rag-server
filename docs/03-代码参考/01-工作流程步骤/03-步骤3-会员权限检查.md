# 步骤3 - 会员权限检查

**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

---

## 概述

步骤3负责检查用户的会员等级，决定后续步骤的功能权限（如模型选择、检索深度）。采用**缓存管理器优先 + 会员缓存降级**策略，并集成智能预热器追踪步骤1预热数据的命中效果。

### 在工作流中的位置

```
步骤1: 预加载用户档案（异步预热步骤3的会员数据）
  ↓
步骤2: 会话记录存储
  ↓
步骤3: 会员权限检查 ⭐ ← 当前
  ↓  输出 membership_info, is_premium → 写入 WorkflowState
步骤4: BGE复杂度分类
```

## 执行逻辑

### 快速返回路径

```python
# 无 user_id → 匿名用户，直接返回
if not user_id:
    return StateUpdate(updates={"membership_info": None, "is_premium": False})

# user_id 格式无效（非数字） → 匿名模式
if not (isinstance(user_id, int) or (isinstance(user_id, str) and user_id.isdigit())):
    return StateUpdate(updates={"membership_info": None, "is_premium": False})
```

### 两级降级策略

```
Level 1: cache_manager（缓存优先 + 自动回源）
    ├── cache_key = f"user_membership:{user_id_int}"
    ├── 缓存命中 → 直接返回
    └── 缓存未命中 → 调用 membership_cache.get_user_membership() 回源
         └── 写入缓存（TTL=600s / 10分钟）
    ↓ cache_manager 不可用
Level 2: membership_cache（直接查询会员缓存）
    ↓ 全部不可用或返回 None
匿名模式: membership_info=None, is_premium=False
```

核心代码：

```python
# Level 1: 缓存管理器
if cache_manager:
    cache_key = f"user_membership:{user_id_int}"

    async def fetch_membership():
        if membership_cache:
            return await membership_cache.get_user_membership(str(user_id_int))
        return None

    membership = await cache_manager.get(
        key=cache_key, fetch_func=fetch_membership, ttl=600
    )

# Level 2: 会员缓存
elif membership_cache:
    membership = await membership_cache.get_user_membership(str(user_id_int))
```

### 会员等级判定

```python
if membership:
    tier = membership.get('tier', 'free')
    is_fallback = membership.get('_fallback', False)  # 是否为降级数据
    is_premium = tier != 'free'
```

## 预热效果追踪

当缓存命中时，调用 `_record_preload_cache_hit()` 记录预热效果：

```python
if cache_hit:
    await _record_preload_cache_hit(str(user_id_int), smart_preloader, request_id)
```

### `_record_preload_cache_hit` 辅助函数

- 用于追踪步骤1预热步骤3数据的效果（Requirements 3.3）
- `USE_NEW_CACHE` 环境变量控制新旧预热系统切换
- 当前新预热系统暂不支持 `record_cache_hit` 方法，仅记录 debug 日志
- 失败不影响主工作流

---

## 错误处理

| 场景 | 处理方式 | 返回值 |
|------|---------|--------|
| `user_id` 为空 | 跳过检查 | `membership_info=None, is_premium=False` |
| `user_id` 格式无效 | 匿名模式 | `membership_info=None, is_premium=False` |
| 缓存/API 调用异常 | `except Exception` 捕获 | `membership_info=None, is_premium=False` + `warning` |
| 预热追踪失败 | 仅记录日志 | 不影响返回值 |

## 与后续步骤的数据流

### 输出到步骤5（智能模型选择）

`state["is_premium"]` 影响模型选择策略：付费用户可使用更强的模型。

### 输出到步骤7（DAG 编排器）

`state["membership_info"]` 中的 `tier` 影响 DAG 工具的执行深度和功能范围。

### 输出到步骤10（LLM 深度分析）

`state["is_premium"]` 影响 LLM 响应的详细程度和个性化水平。
