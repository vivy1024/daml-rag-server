## LLMResponseConfigManager

### 核心方法

#### 1. `get_config(template_id: str) -> LLMResponseConfig`

根据模板ID返回 LLM 配置：

```python
@dataclass
class LLMResponseConfig:
    max_tokens: int        # 最大token数
    temperature: float     # 温度参数（0-1）
    response_format: str   # 响应格式（text/json）
```

**默认配置**：
- `max_tokens`: 2000
- `temperature`: 0.7
- `response_format`: "text"

**模板特定配置**（示例）：
- `training_plan_design`: `max_tokens=3000, temperature=0.6`
- `nutrition_analysis`: `max_tokens=1500, temperature=0.5`

#### 2. `build_prompt(...) -> str`

构建完整的系统提示词：

```python
def build_prompt(
    self,
    template_id: str,
    query: str,
    user_profile: str,
    response_hint: str,
    mcp_tools_count: int,
    retrieval_count: int,
    mcp_tools_result: str
) -> str:
```

## 提示词结构

### 基础模板

```
你是玉珍健身的专业AI助手，专注于提供科学、个性化的健身指导。

## 用户档案
{user_profile}

## 用户查询
{query}

## 可用数据
- MCP工具调用结果: {mcp_tools_count}个
- 知识库检索结果: {retrieval_count}个

## MCP工具结果
{mcp_tools_result}

## 响应要求
{response_hint}

请基于以上信息，提供专业、详细的回答。
```

### 模板特定增强

不同 DAG 模板会添加特定的响应要求：

#### `training_plan_design`（训练计划设计）

```
## 响应要求
1. 基于用户档案（年龄、性别、训练水平、可用器械）设计个性化计划
2. 考虑健康档案中的损伤史和禁忌症
3. 提供详细的动作说明、组数、次数、重量建议
4. 包含渐进式超负荷策略
5. 格式清晰，易于执行
```

#### `nutrition_analysis`（营养分析）

```
## 响应要求
1. 基于用户目标（增肌/减脂）计算TDEE和宏量营养素
2. 提供具体的食物建议和份量
3. 考虑用户的饮食偏好和限制
4. 包含补剂建议（如需要）
5. 提供实用的饮食时间安排
```

## LLM 参数配置

### max_tokens

| 模板类型 | max_tokens | 说明 |
|---------|-----------|------|
| `greeting` | 500 | 简单问候，短响应 |
| `quick_consultation` | 1500 | 快速咨询，中等长度 |
| `training_plan_design` | 3000 | 训练计划，需要详细输出 |
| `nutrition_analysis` | 2000 | 营养分析，中长响应 |
| `injury_assessment` | 2500 | 损伤评估，需要详细说明 |

### temperature

| 模板类型 | temperature | 说明 |
|---------|------------|------|
| `greeting` | 0.8 | 较高创造性，友好自然 |
| `quick_consultation` | 0.7 | 平衡创造性和准确性 |
| `training_plan_design` | 0.6 | 偏保守，确保科学性 |
| `nutrition_analysis` | 0.5 | 低温度，精确计算 |
| `injury_assessment` | 0.4 | 极低温度，严谨专业 |

## 特殊处理：训练计划分周输出

当 MCP 工具返回完整训练计划时，`WeeklyPlanGenerator` 会将其转换为单周输出：

```python
from ..services.weekly_plan_generator import WeeklyPlanGenerator

weekly_generator = WeeklyPlanGenerator()
weekly_plan = weekly_generator.generate_first_week(
    full_program=program_result,
    user_profile=user_profile,
    total_weeks=total_weeks
)

weekly_plan_output = weekly_generator.convert_to_output_format(weekly_plan)
program_result["weekly_plan_output"] = weekly_plan_output
program_result["output_mode"] = "weekly"
```

**原因**：完整计划（4-12周）token消耗过大，单周输出更适合 LLM 处理和用户阅读。
