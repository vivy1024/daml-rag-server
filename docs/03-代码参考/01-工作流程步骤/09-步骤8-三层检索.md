**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

## 概述

步骤8负责从知识库检索相关上下文，支持**意图路由**（Phase 4C）：根据查询类型选择最优检索策略。如果步骤7的 DAG 已返回结果，则跳过检索直接使用 DAG 数据。

### 在工作流中的位置

```
步骤7: DAG编排执行
  ↓  dag_results（如果非空则跳过检索）
步骤8: 三层检索 ⭐ ← 当前
  ↓  输出 retrieval_results → 写入 WorkflowState
步骤9: 工具结果汇总
```

## 执行逻辑

### 0. DAG结果快速返回

```python
if dag_results:
    return StateUpdate(updates={
        "retrieval_results": {
            "results": _convert_dag_results_to_list(dag_results),
            "query_type": "dag_orchestration",
            "domain": domain,
            "count": len(dag_results)
        }
    })
```

### 1. 意图分类

```python
from ....framework.retrieval.intent_classifier import classify_intent, QueryIntent

intent_result = classify_intent(query_text)
# intent_result.intent: STRUCTURED | SEMANTIC | HYBRID
# intent_result.structured_type: EXERCISE_DETAILS | NUTRITION_INFO | ...
# intent_result.extracted_entity: "深蹲" | "鸡胸肉" | ...
```

### 2. 路由策略

#### 路由1: structured → Neo4j Cypher 直查

适用于结构化查询（如"深蹲的动作要领"、"鸡胸肉的营养成分"）：

```python
if (intent_result.intent == QueryIntent.STRUCTURED
        and intent_result.structured_type
        and intent_result.extracted_entity):
    
    neo4j_results = cypher_executor.execute(
        query_type=intent_result.structured_type,
        entity=intent_result.extracted_entity,
        limit=10
    )
    
    if neo4j_results:
        return StateUpdate(updates={"retrieval_results": {...}})
```

**性能**：~50ms（跳过向量检索）

#### 路由2: hybrid → Neo4j + HybridSearch 融合

适用于混合查询（既需要结构化数据，又需要语义检索）：

```python
if intent_result.intent == QueryIntent.HYBRID:
    # 1. Neo4j 结构化补充
    neo4j_results = cypher_executor.execute(
        query_type=StructuredQueryType.EXERCISE_DETAILS,
        entity=intent_result.extracted_entity,
        limit=5
    )
    
    # 2. 混合检索
    hybrid_results = await hybrid_search_engine.hybrid_search(
        query=query_text, domain=domain, top_k=10
    )
    
    # 3. 融合（Neo4j 排前，HybridSearch 排后，去重）
    merged = _merge_results(neo4j_results, hybrid_results, max_total=10)
    
    return StateUpdate(updates={"retrieval_results": {...}})
```

#### 路由3: semantic → HybridSearch

适用于语义查询（如"如何提高卧推力量"）：

```python
if hybrid_search_engine:
    hybrid_results = await hybrid_search_engine.hybrid_search(
        query=query_text, domain=domain, top_k=10
    )
    
    return StateUpdate(updates={"retrieval_results": {...}})
```

**性能**：~200ms（BM25 + 向量 + RRF）

### 3. 降级链

```
HybridSearch 失败
  ↓
GraphRAG 检索
  ↓
旧三层检索引擎
  ↓
空结果
```

---

## 错误处理

| 场景 | 处理方式 | 返回值 |
|------|---------|--------|
| 意图分类失败 | 降级到混合检索 | 继续执行 |
| Neo4j 直查失败 | 降级到混合检索 | 继续执行 |
| 混合检索失败 | 降级到 GraphRAG | 继续执行 |
| 所有检索失败 | 返回空结果 | `results=[]` + `error` |
| 无检索引擎 | 返回空结果 | `results=[]` + `warning` |
