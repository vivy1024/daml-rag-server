### LLM分析引擎

```python
class LLMAnalysisEngine:
    """
    LLM分析引擎
    
    职责：
    - 基于真实工具结果进行专业分析
    - 提供个性化建议
    - 确保所有建议可追溯到数据源
    """
    
    async def analyze_and_synthesize(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        tool_results: Dict[str, Any]
    ) -> str:
        """
        分析并综合工具结果
        
        Args:
            user_query: 用户查询
            user_profile: 用户档案
            tool_results: 工具执行结果
            
        Returns:
            LLM生成的专业分析和建议
        """
        # 1. 构建分析提示词
        prompt = self._build_analysis_prompt(
            user_query, user_profile, tool_results
        )
        
        # 2. 调用LLM
        response = await self.llm_client.chat(prompt)
        
        # 3. 验证响应（确保不推荐禁忌动作）
        validated_response = self._validate_response(
            response, tool_results.get("contraindications", [])
        )
        
        return validated_response
    
    def _build_analysis_prompt(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        tool_results: Dict[str, Any]
    ) -> str:
        """构建分析提示词"""
        return f"""
你是玉珍健身专业教练。基于以下真实数据，为用户提供专业的健身指导。

## 用户查询
{user_query}

## 用户档案
- 年龄：{user_profile['age']}岁
- 训练水平：{user_profile['fitness_level']}
- 健身目标：{user_profile['fitness_goals']}
- 健康状况：{user_profile['health_conditions']}

## 工具执行结果（真实数据）

### ❌ 禁忌动作（必须避免）
{json.dumps(tool_results['contraindications'], ensure_ascii=False, indent=2)}

### ✅ 推荐动作
{json.dumps(tool_results['selected_exercises'], ensure_ascii=False, indent=2)}

### 📊 训练计划
{json.dumps(tool_results['training_program'], ensure_ascii=False, indent=2)}

## 你的任务
1. **专业分析**：分析训练计划的合理性、科学性
2. **个性化建议**：基于用户的具体情况（如{user_profile['health_conditions']}），提供针对性建议
3. **安全强调**：明确指出禁忌动作，解释为什么要避免
4. **推理依据**：说明你的建议基于哪些具体数据

## ⚠️ 约束条件
- ❌ 绝对不要推荐禁忌动作中的任何动作
- ✅ 所有建议必须基于上述真实数据
- ✅ 数据不足时明确告知，不要猜测
- ✅ 提供推理依据，确保可追溯

请生成你的专业建议：
"""
```

## 结构化数据检测（流式输出）

### 概述

在流式输出模式下，系统会实时检测LLM生成的文本流中是否包含结构化数据标记，并自动提取JSON数据发送给前端。

### 支持的数据类型

系统支持以下三种结构化数据类型：

1. **训练计划** (`TRAINING_PLAN`)
   - 标记格式：`[TRAINING_PLAN:{...}]`
   - 用途：完整的训练计划数据
   - 前端渲染：训练计划卡片组件

2. **营养数据** (`NUTRITION_DATA`)
   - 标记格式：`[NUTRITION_DATA:{...}]`
   - 用途：营养摄入分析、膳食计划
   - 前端渲染：营养图表组件

3. **进度图表** (`PROGRESS_CHART`)
   - 标记格式：`[PROGRESS_CHART:{...}]`
   - 用途：训练进度、体重变化等数据
   - 前端渲染：进度图表组件

### 检测逻辑实现

**文件位置**: `src/applications/fitness/workflow_executor.py` (第1513-1575行)

```python
# 检测结构化数据标记（支持多种类型）
if not structured_data_extracted:
    # 定义支持的结构化数据类型及其标记
    structured_data_markers = {
        "TRAINING_PLAN": "training_plan",
        "NUTRITION_DATA": "nutrition_data",
        "PROGRESS_CHART": "progress_chart"
    }
    
    # 遍历所有支持的标记类型
    for marker, data_type in structured_data_markers.items():
        marker_tag = f"[{marker}:"
        
        if marker_tag in full_response:
            # 尝试提取JSON数据
            try:
                start_idx = full_response.find(marker_tag)
                if start_idx != -1:
                    json_start = start_idx + len(marker_tag)
                    
                    # 查找JSON对象的结束标记
                    potential_end = full_response.find("}]", json_start)
                    
                    if potential_end != -1:
                        # 找到了完整的JSON
                        json_str = full_response[json_start:potential_end + 1]
                        
                        try:
                            structured_data = json.loads(json_str)
                            structured_data_count += 1
                            structured_data_extracted = True
                            
                            # 发送SSE事件
                            yield {
                                "type": "structured_data",
                                "data_type": data_type,
                                "data": structured_data
                            }
                            
                            logger.info(
                                f"📦 [{request_id}] 检测到结构化数据: "
                                f"type={data_type}, "
                                f"marker={marker}, "
                                f"size={len(json_str)}字节"
                            )
                            
                            # 找到一个就跳出循环
                            break
                            
                        except json.JSONDecodeError as json_err:
                            # JSON解析失败，可能还没接收完整
                            logger.debug(
                                f"   [{request_id}] JSON尚未完整，继续等待... "
                                f"marker={marker}, "
                                f"(已接收{len(json_str)}字节)"
                            )
            except Exception as e:
                logger.warning(
                    f"⚠️ [{request_id}] 提取结构化数据失败: "
                    f"marker={marker}, error={e}"
                )
```

### SSE事件格式

当检测到结构化数据时，系统会发送以下格式的SSE事件：

```json
{
  "type": "structured_data",
  "data_type": "training_plan",  // 或 "nutrition_data", "progress_chart"
  "data": {
    // 具体的JSON数据
    "plan_name": "4周增肌计划",
    "duration_weeks": 4,
    // ...
  }
}
```

### 前端处理

前端接收到 `structured_data` 事件后，根据 `data_type` 字段渲染对应的组件：

```typescript
eventSource.addEventListener('structured_data', (event) => {
  const data = JSON.parse(event.data)
  
  switch (data.data_type) {
    case 'training_plan':
      // 渲染训练计划卡片
      renderTrainingPlanCard(data.data)
      break
    case 'nutrition_data':
      // 渲染营养图表
      renderNutritionChart(data.data)
      break
    case 'progress_chart':
      // 渲染进度图表
      renderProgressChart(data.data)
      break
  }
})
```

### 配置要求

为了让LLM生成包含结构化数据标记的内容，需要在 `llm_response_config.yaml` 中配置 `response_hint`：

```yaml
templates:
  complete_training_plan:
    response_hint: |
      请在生成训练计划时，使用以下格式嵌入结构化数据：
      [TRAINING_PLAN:{"plan_name":"...","training_days":...}]
      
      示例：
      [TRAINING_PLAN:{"plan_name":"4周增肌计划","training_days":[...]}]
```
