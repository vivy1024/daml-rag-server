# 工作流程执行器

**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

---

## 概述

工作流程执行器是 DAML-RAG 系统的**入口点**，负责初始化所有组件并执行完整的 11 步工作流程。当前实现已迁移到 `workflow/` 模块，采用 **LangGraph StateGraph** 架构。

---

## 源码位置

| 文件 | 说明 |
|------|------|
| `src/applications/fitness/workflow_executor.py` | 向后兼容层（导入 workflow 模块） |
| `src/applications/fitness/workflow/executor.py` | 同步执行器 `WorkflowExecutor` |
| `src/applications/fitness/workflow/stream_executor.py` | 流式执行器 `StreamWorkflowExecutor` |
| `src/applications/fitness/workflow/graph.py` | StateGraph 图构建 |
| `src/applications/fitness/workflow/nodes.py` | 节点函数（步骤1-11） |
| `src/applications/fitness/workflow/edges.py` | 边定义（条件路由） |
| `src/applications/fitness/workflow/state.py` | 状态定义 `WorkflowState` |

## 核心接口

### 1. 同步执行

```python
from src.applications.fitness.workflow_executor import execute_eleven_step_workflow

result = await execute_eleven_step_workflow(
    user_id=123,
    query_text="如何提高卧推力量？",
    session_id="session_123",
    domain="fitness",
    template_id=None,  # 可选：强制指定 DAG 模板
    conversation_topic_id=None,  # 可选：指定对话话题
)

# result: WorkflowState（包含所有步骤的输出）
final_response = result["final_response"]
```

### 2. 流式执行

```python
from src.applications.fitness.workflow_executor import execute_eleven_step_workflow_stream

async for chunk in execute_eleven_step_workflow_stream(
    user_id=123,
    query_text="如何提高卧推力量？",
    session_id="session_123",
    domain="fitness",
):
    # chunk: Dict[str, Any]
    # 包含当前步骤的输出和进度信息
    if "final_response" in chunk:
        print(chunk["final_response"])
```

## WorkflowExecutor 类

### 初始化

```python
from src.applications.fitness.workflow import WorkflowExecutor

executor = WorkflowExecutor()
```

**自动初始化的组件**：
- 缓存管理器（`CacheManager`）
- 用户缓存（`UserCache`）
- 会员缓存（`MembershipCache`）
- 后端客户端（`BackendClient`）
- 对话记忆（`ConversationMemory`）
- DAG 模板管理器（`DAGTemplateManager`）
- LLM 降级管理器（`LLMFallbackManager`）
- 检索引擎（`HybridSearchEngine`、`GraphRAGRetriever`）
- ...

### 执行工作流

```python
result = await executor.execute(
    user_id=123,
    query_text="如何提高卧推力量？",
    session_id="session_123",
    domain="fitness",
)
```

## StateGraph 架构

工作流使用 LangGraph 的 `StateGraph` 构建，每个步骤是一个节点，节点间通过边连接。

### 节点（步骤）

```python
# 步骤1-11
graph.add_node("step1_preload_user_profile", node_preload_user_profile)
graph.add_node("step2_store_session", node_store_session)
graph.add_node("step3_check_membership", node_check_membership)
graph.add_node("step4_classify_complexity", node_classify_complexity)
graph.add_node("step5_select_model", node_select_model)
graph.add_node("step6_retrieve_few_shot", node_retrieve_few_shot)
graph.add_node("step6_5_select_dag_template", node_select_dag_template)
graph.add_node("step7_execute_dag", node_execute_dag)
graph.add_node("step8_retrieve_context", node_retrieve_context)
graph.add_node("step9_aggregate_data", node_aggregate_data)
graph.add_node("step10_llm_analysis", node_llm_analysis)
graph.add_node("step11_log_interaction", node_log_interaction)
```

### 边（路由）

```python
# 线性路由（大部分步骤）
graph.add_edge("step1_preload_user_profile", "step2_store_session")
graph.add_edge("step2_store_session", "step3_check_membership")
# ...

# 条件路由（预留扩展）
# graph.add_conditional_edges("step4_classify_complexity", route_by_complexity)
```

### 入口和出口

```python
graph.set_entry_point("step1_preload_user_profile")
graph.set_finish_point("step11_log_interaction")
```

## WorkflowState

工作流状态是一个 `TypedDict`，包含所有步骤的输入和输出：

```python
class WorkflowState(TypedDict, total=False):
    # 输入
    request_id: str
    user_id: int | str
    query_text: str
    session_id: str
    domain: str
    template_id: str | None
    conversation_topic_id: str | None
    
    # 步骤1输出
    user_profile: Dict | None
    
    # 步骤2输出
    conversation_history: List[Dict]
    
    # 步骤3输出
    membership_info: Dict | None
    is_premium: bool
    
    # 步骤4输出
    complexity_level: str
    
    # 步骤5输出
    selected_model: str
    
    # 步骤6输出
    few_shot_examples: List[Dict]
    
    # 步骤6.5输出
    dag_template_id: str
    
    # 步骤7输出
    dag_results: Dict | None
    
    # 步骤8输出
    retrieval_results: Dict
    
    # 步骤9输出
    aggregated_data: Dict
    _mcp_tools_called: List[str]
    
    # 步骤10输出
    final_response: str
    
    # 步骤11输出
    interaction_logged: bool
    
    # 错误和警告
    errors: List[str]
    warnings: List[str]
```

## 单例管理

框架层组件使用单例模式，避免重复初始化：

```python
from src.applications.fitness.workflow import (
    get_user_cache,
    get_membership_cache,
    get_cache_manager,
    reset_all_singletons,
)

# 获取单例
user_cache = get_user_cache()

# 重置所有单例（测试用）
reset_all_singletons()
```
