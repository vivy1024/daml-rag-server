## 概述

步骤5基于步骤4的BGE复杂度分类结果和步骤6的Few-Shot检索结果，智能选择使用教师模型（DeepSeek）还是学生模型（Anthropic Claude Qwen2.5:7b）。

### 三段式决策逻辑

```python
def _should_use_teacher_model(similarity: float, few_shot_count: int) -> bool:
    """
    三段式决策：
    1. similarity < 0.5  → 学生模型（Anthropic Claude，免费）
    2. similarity >= 0.7 → 教师模型（DeepSeek，付费）
    3. 0.5 <= similarity < 0.7 → 检查Few-Shot
       - Few-Shot >= 3 → 学生模型（有足够示例）
       - Few-Shot < 3  → 教师模型（保险）
    """
    if similarity < 0.5:
        return False  # 学生模型
    elif similarity >= 0.7:
        return True   # 教师模型
    else:
        # 灰色地带：检查Few-Shot
        return few_shot_count < 3
```
