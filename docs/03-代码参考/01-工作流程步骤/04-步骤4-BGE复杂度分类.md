**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

## 概述

步骤4使用 BGE 嵌入模型对用户查询进行复杂度分类，决定后续步骤5的模型选择策略。当 `DUAL_MODEL_ENABLED=false` 时（当前默认），此步骤**快速跳过**，直接返回 `complex` 级别使用 DeepSeek。

### 在工作流中的位置

```
步骤3: 会员权限检查
  ↓
步骤4: BGE复杂度分类 ⭐ ← 当前
  ↓  输出 complexity_level → 写入 WorkflowState
步骤5: 智能模型选择（根据复杂度选择模型）
```

## 函数签名

```python
async def node_classify_complexity(
    state: WorkflowState,
    classifier=None,
    cache_manager=None
) -> StateUpdate:
```

### 参数说明

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `state` | `WorkflowState` | ✅ | 当前工作流状态，包含 `request_id`、`query_text` |
| `classifier` | `QueryComplexityClassifier \| None` | ❌ | 复杂度分类器，未传入时延迟导入创建 |
| `cache_manager` | `CacheManager \| None` | ❌ | 缓存管理器，缓存分类结果 |

### 返回值

```python
StateUpdate(updates={
    "complexity_level": str,          # "simple" | "moderate" | "complex"
    "_complexity_similarity": float,  # 相似度分数（内部指标）
    "_complexity_reason": str,        # 分类原因（内部指标）
})
```

## 执行逻辑

### Feature Flag 快速跳过

```python
dual_model_enabled = os.getenv("DUAL_MODEL_ENABLED", "false").lower() == "true"
if not dual_model_enabled:
    # 双模型选择已禁用，直接返回 complex → 使用 DeepSeek
    return StateUpdate(updates={
        "complexity_level": "complex",
        "_complexity_similarity": 1.0,
        "_complexity_reason": "双模型选择已禁用"
    })
```

> **当前生产环境 `DUAL_MODEL_ENABLED=false`**，此步骤实际上总是快速跳过。以下逻辑仅在启用双模型时执行。

### 分类流程（双模型启用时）

```python
# 1. 延迟导入分类器
if classifier is None:
    from ....framework.models.query_complexity_classifier import QueryComplexityClassifier
    classifier = QueryComplexityClassifier()

# 2. 生成缓存键（基于查询文本 MD5）
query_hash = hashlib.md5(query_text.encode('utf-8')).hexdigest()
cache_key = f"bge_complexity:{query_hash}"

# 3. 缓存优先查询
if cache_manager:
    result = await cache_manager.get(
        key=cache_key, fetch_func=fetch_complexity, ttl=3600  # 1小时TTL
    )
else:
    result = classifier.classify_complexity(query_text)
```

### 复杂度级别判定

```python
is_complex = result.is_complex
similarity = result.similarity

if is_complex:
    complexity_level = "complex"      # 复杂查询 → DeepSeek（教师模型）
elif similarity >= 0.5:
    complexity_level = "moderate"     # 中等查询
else:
    complexity_level = "simple"       # 简单查询 → 可用轻量模型（学生模型）
```

---

## 错误处理

| 场景 | 处理方式 | 返回值 |
|------|---------|--------|
| 双模型禁用 | 快速跳过 | `complexity_level="complex"` |
| 分类器导入失败 | `except Exception` 捕获 | `complexity_level="simple"` + `warning` |
| 分类执行异常 | `except Exception` 捕获 | `complexity_level="simple"` + `warning` |

降级策略：分类失败时默认为 `simple`（使用轻量模型），与快速跳过时默认 `complex` 不同。

| `simple` | 可用轻量模型（学生模型） |
