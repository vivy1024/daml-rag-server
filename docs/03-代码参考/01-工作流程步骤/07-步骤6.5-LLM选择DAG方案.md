## 概述

步骤6.5是三段式架构的核心创新：LLM分析用户查询，从预定义的DAG模板库中选择最合适的工作流程方案。这避免了LLM直接调用MCP工具可能产生的幻觉问题。

### 在11步工作流程中的位置

```
【阶段1：LLM决策层】
步骤6.5: LLM选择DAG方案 ⭐⭐⭐ ← 三段式核心
  ↓
【阶段2：程序执行层】
步骤7: DAG编排器（执行选中的DAG）
```

### LLM决策引擎

```python
class LLMDecisionEngine:
    """
    LLM决策引擎
    
    职责：
    - 理解用户意图
    - 从DAG模板库中选择最合适的方案
    - 避免LLM直接调用MCP工具
    """
    
    async def select_dag_template(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        available_templates: List[DAGTemplate]
    ) -> DAGSelectionResult:
        """
        选择DAG模板
        
        Args:
            user_query: 用户查询
            user_profile: 用户档案
            available_templates: 可用的DAG模板列表
            
        Returns:
            DAGSelectionResult: 选择结果
        """
        # 1. 构建提示词
        prompt = self._build_selection_prompt(
            user_query, user_profile, available_templates
        )
        
        # 2. 调用LLM
        response = await self.llm_client.chat(prompt)
        
        # 3. 解析LLM响应
        selection = self._parse_llm_response(response)
        
        # 4. 验证选择的有效性
        if not self._validate_selection(selection, available_templates):
            logger.warning("LLM选择无效，降级到规则匹配")
            selection = self._fallback_rule_matching(user_query)
        
        return selection
    
    def _build_selection_prompt(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        available_templates: List[DAGTemplate]
    ) -> str:
        """构建LLM提示词"""
        return f"""
你是专业的健身AI助手。分析用户查询，选择最合适的工作流程。

## 用户信息
- 查询：{user_query}
- 年龄：{user_profile['age']}岁
- 训练水平：{user_profile['fitness_level']}
- 健身目标：{user_profile['fitness_goals']}
- 健康状况：{user_profile['health_conditions']}

## 可选的工作流程（DAG模板）

1. **完整训练计划** (complete_training_plan)
   - 适用于：制定训练计划、增肌计划、力量训练
   - 工具链：用户档案 → 禁忌检查 → 动作选择 → 训练量计算 → 计划设计
   
2. **营养规划** (nutrition_planning)
   - 适用于：饮食建议、营养搭配、餐食计划
   - 工具链：用户档案 → TDEE计算 → 营养分析 → 餐食设计
   
3. **动作优化** (exercise_optimization)
   - 适用于：动作选择、替代动作、动作修正
   - 工具链：用户档案 → 禁忌检查 → 动作选择 → 替代方案
   
4. **安全评估** (safety_assessment)
   - 适用于：禁忌动作、风险评估、安全检查
   - 工具链：用户档案 → 禁忌检查 → 风险评估 → 安全建议
   
5. **进展分析** (progress_analysis)
   - 适用于：训练效果、进度追踪、数据分析
   - 工具链：用户档案 → 训练数据 → 分析仪表板 → 建议生成

请选择最合适的工作流程，输出JSON格式：
{{
  "selected_template_id": "complete_training_plan",
  "selection_reason": "用户明确要求制定增肌训练计划，需要完整的工具链",
  "confidence": 0.95,
  "expected_tools": ["get_user_profile", "contraindications_checker", ...]
}}
"""
```

### DAG模板定义

```python
@dataclass
class DAGTemplate:
    """DAG模板数据结构"""
    template_id: str
    name: str
    description: str
    applicable_scenarios: List[str]
    required_tools: List[str]
    tool_dependencies: Dict[str, List[str]]
    estimated_duration: float  # 预估执行时间（秒）
    
# 示例：完整训练计划模板
COMPLETE_TRAINING_PLAN_TEMPLATE = DAGTemplate(
    template_id="complete_training_plan",
    name="完整训练计划",
    description="制定个性化的训练计划，包含动作选择、训练量计算、周期化设计",
    applicable_scenarios=[
        "制定训练计划",
        "增肌计划",
        "力量训练",
        "健身规划"
    ],
    required_tools=[
        "get_user_profile",
        "contraindications_checker",
        "injury_risk_assessor",
        "intelligent_exercise_selector",
        "muscle_group_volume_calculator",
        "professional_program_designer"
    ],
    tool_dependencies={
        "get_user_profile": [],
        "contraindications_checker": ["get_user_profile"],
        "injury_risk_assessor": ["get_user_profile"],
        "intelligent_exercise_selector": ["contraindications_checker", "injury_risk_assessor"],
        "muscle_group_volume_calculator": ["get_user_profile"],
        "professional_program_designer": ["intelligent_exercise_selector", "muscle_group_volume_calculator"]
    },
    estimated_duration=3.5
)
```

## 关键优势

### 1. 避免LLM幻觉

```python
# ❌ 旧方式：LLM直接调用MCP工具（容易幻觉）
llm_response = """
我建议调用以下工具：
1. get_user_profile
2. check_contraindications  # ❌ 工具名错误！
3. design_super_program     # ❌ 不存在的工具！
"""

# ✅ 新方式：LLM只从预定义模板中选择
llm_response = """
{
  "selected_template_id": "complete_training_plan",  # ✅ 从模板库选择
  "confidence": 0.95
}
"""
```

### 2. 灵活扩展

```python
# 新增DAG模板无需修改LLM提示词
new_template = DAGTemplate(
    template_id="rehabilitation_program",
    name="康复训练计划",
    description="针对损伤康复的专业训练方案",
    applicable_scenarios=["康复训练", "损伤恢复", "物理治疗"],
    required_tools=[...],
    tool_dependencies={...}
)

# 自动加入模板库
template_manager.register_template(new_template)

# LLM自动识别新模板（无需重新训练）
```

### 3. 降级策略

```python
def _fallback_rule_matching(self, user_query: str) -> DAGSelectionResult:
    """LLM选择失败时的降级策略"""
    # 规则匹配
    if any(keyword in user_query for keyword in ["训练计划", "增肌", "力量"]):
        return DAGSelectionResult(
            template_id="complete_training_plan",
            confidence=0.6,
            selection_method="rule_matching"
        )
    elif any(keyword in user_query for keyword in ["饮食", "营养", "餐食"]):
        return DAGSelectionResult(
            template_id="nutrition_planning",
            confidence=0.6,
            selection_method="rule_matching"
        )
    else:
        # 默认使用最通用的模板
        return DAGSelectionResult(
            template_id="exercise_optimization",
            confidence=0.5,
            selection_method="default"
        )
```
