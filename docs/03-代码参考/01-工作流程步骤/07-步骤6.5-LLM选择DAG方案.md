# 步骤6.5 - LLM选择DAG方案

**版本**: v1.1.0
**创建日期**: 2026-02-21
**状态**: 持续更新

---

## 概述

步骤6.5是工作流的**关键决策点**，负责选择最合适的 DAG 模板来处理用户查询。支持**用户强制指定**和 **LLM智能选择**两种模式，并集成**会员权限检查**，无权限时自动降级到免费模板。

### 在工作流中的位置

```
步骤6: Few-Shot检索
  ↓  few_shot_examples
步骤6.5: LLM选择DAG方案 ⭐ ← 当前
  ↓  输出 dag_template_id → 写入 WorkflowState
步骤7: DAG编排执行（根据 dag_template_id 执行对应 DAG）
```

## 函数签名

```python
async def node_select_dag_template(
    state: WorkflowState,
    template_manager=None,
    decision_engine=None
) -> StateUpdate:
```

### 参数说明

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `state` | `WorkflowState` | ✅ | 当前工作流状态，包含 `request_id`、`query_text`、`user_profile`、`session_id`、`few_shot_examples`、`membership_info`、`template_id` |
| `template_manager` | `DAGTemplateManager \| None` | ❌ | DAG模板管理器，未传入时自动创建 |
| `decision_engine` | `LLMDecisionEngine \| None` | ❌ | LLM决策引擎，未传入时自动创建 |

### 返回值

```python
StateUpdate(updates={
    "dag_template_id": str,                    # 最终选择的模板ID
    "_dag_selection_confidence": float,        # 选择置信度（0-1）
    "_dag_selection_reason": str,              # 选择原因
    "_original_template_id": str,              # LLM原始选择的模板ID
    "_force_template_used": bool,              # 是否使用了强制指定
    "_permission_denied": bool,                # 是否因权限不足降级
    "_upgrade_message": str | None,            # 升级提示消息
    "_user_tier": str,                         # 用户会员等级
    "_available_templates_count": int,         # 可用模板数量
    "_total_templates_count": int,             # 总模板数量
})
```

## 执行逻辑

### 1. 检查用户强制指定

```python
force_template_id = state.get("template_id")

if force_template_id:
    # 验证模板ID是否有效
    template = template_manager.get_template(force_template_id)
    if template:
        original_template_id = force_template_id
        # 跳过 LLM 选择，直接进入权限检查
    else:
        # 无效模板ID，回退到 LLM 选择
        force_template_id = None
```

### 2. LLM智能选择（未强制指定时）

```python
if not force_template_id:
    # 初始化决策引擎
    if decision_engine is None:
        decision_engine = LLMDecisionEngine(template_manager)
    
    # 创建选择请求
    selection_request = DAGSelectionRequest(
        user_query=query_text,
        user_profile=user_profile or {},
        available_templates=template_manager.get_all_templates(),
        session_context={"session_id": session_id},
        few_shot_examples=few_shot_examples
    )
    
    # LLM选择DAG模板
    selection_result = await decision_engine.select_dag_template(selection_request)
    original_template_id = selection_result.selected_template_id
```

### 3. 会员权限检查

```python
from ..services.dag_template_permission import (
    check_template_permission,
    get_user_membership_tier,
    get_template_count_by_tier
)

permission_result = check_template_permission(original_template_id, membership_info)
user_tier = get_user_membership_tier(membership_info)
available_count, total_count = get_template_count_by_tier(user_tier)

if permission_result.allowed:
    # 有权限，使用原始选择
    selected_template_id = original_template_id
else:
    # 无权限，使用降级模板
    selected_template_id = permission_result.fallback_template_id or "quick_consultation"
    permission_denied = True
    upgrade_message = permission_result.message
```

### 会员等级与模板对应（MVP阶段）

| 会员等级 | 可用模板数 | 说明 |
|---------|----------|------|
| 免费版 | 2 | `greeting`, `quick_consultation` |
| 暖心会员 | 13 | 全部模板（¥6首充福利） |
| 能量会员 | - | 暂不开放（等Agent模式开发完成） |

## 错误处理

### 主路径异常

```python
except Exception as e:
    # 降级到规则匹配
    selected_template_id = template_manager.match_template_by_keywords(query_text)
    
    # 即使降级也要检查权限
    permission_result = check_template_permission(selected_template_id, membership_info)
    if not permission_result.allowed:
        selected_template_id = permission_result.fallback_template_id or "quick_consultation"
```

### 降级策略也失败

```python
except Exception as fallback_error:
    # 最终降级到免费模板
    selected_template_id = "quick_consultation"
```

## 与后续步骤的数据流

### 输出到步骤7（DAG编排执行）

`state["dag_template_id"]` 决定步骤7执行哪个 DAG 模板：

- `greeting` → 简单问候响应
- `quick_consultation` → 快速咨询（免费版核心功能）
- `training_plan_design` → 训练计划设计（付费功能）
- `nutrition_analysis` → 营养分析（付费功能）
- ...

### 权限检查结果的使用

`_permission_denied` 和 `_upgrade_message` 可在步骤10（LLM深度分析）中用于生成升级提示。
