## 概述

步骤9将DAG执行的所有工具结果汇总为结构化JSON，为步骤10的LLM深度分析提供数据基础。

### 文件位置

- **主文件**: `src/applications/fitness/fitness_orchestrator.py`
- **调用位置**: DAG执行完成后

### 结果汇总

```python
def _aggregate_tool_results(
    self,
    dag_results: Dict[str, Any]
) -> Dict[str, Any]:
    """
    汇总工具结果
    
    将DAG执行的所有工具结果整理为结构化JSON
    """
    aggregated = {
        "user_profile": dag_results.get("get_user_profile", {}),
        "contraindications": dag_results.get("contraindications_checker", []),
        "injury_risks": dag_results.get("injury_risk_assessor", {}),
        "selected_exercises": dag_results.get("intelligent_exercise_selector", []),
        "training_volume": dag_results.get("muscle_group_volume_calculator", {}),
        "training_program": dag_results.get("professional_program_designer", {})
    }
    
    return aggregated
```
