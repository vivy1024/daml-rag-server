## 概述

三段式编排器是DAML-RAG系统的顶层编排器，整合LLM决策、程序执行、LLM综合三个阶段。

### 文件位置

- **主文件**: `src/applications/fitness/three_stage_orchestrator.py`

### 三段式架构

```
【阶段1：LLM决策层】
  LLM理解意图 → 选择DAG方案
  ↓
【阶段2：程序执行层】
  执行DAG → 三层检索 → 结构化结果
  ↓
【阶段3：LLM综合层】
  基于真实数据 → 专业分析 → 生成建议
```

### 核心类：ThreeStageOrchestrator

```python
class ThreeStageOrchestrator:
    """
    三段式编排器
    
    职责：
    - 协调三个阶段的执行
    - 确保数据在阶段间正确传递
    - 处理异常和降级策略
    """
    
    def __init__(
        self,
        llm_decision_engine: LLMDecisionEngine,
        dag_orchestrator: EnhancedDAGOrchestrator,
        llm_analysis_engine: LLMAnalysisEngine
    ):
        self.llm_decision_engine = llm_decision_engine
        self.dag_orchestrator = dag_orchestrator
        self.llm_analysis_engine = llm_analysis_engine
    
    async def execute(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        context: Dict[str, Any]
    ) -> Dict[str, Any]:
        """
        执行三段式工作流程
        
        Args:
            user_query: 用户查询
            user_profile: 用户档案
            context: 执行上下文
            
        Returns:
            AI响应和元数据
        """
        # 【阶段1：LLM决策层】
        logger.info("阶段1: LLM决策层")
        dag_selection = await self._stage1_llm_decision(
            user_query, user_profile, context
        )
        
        # 【阶段2：程序执行层】
        logger.info("阶段2: 程序执行层")
        tool_results = await self._stage2_program_execution(
            dag_selection, user_profile, context
        )
        
        # 【阶段3：LLM综合层】
        logger.info("阶段3: LLM综合层")
        ai_response = await self._stage3_llm_synthesis(
            user_query, user_profile, tool_results, context
        )
        
        return {
            "response": ai_response,
            "metadata": {
                "selected_template": dag_selection.template_id,
                "tools_called": list(tool_results.keys()),
                "execution_time": context.get("execution_time")
            }
        }
    
    async def _stage1_llm_decision(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        context: Dict[str, Any]
    ) -> DAGSelectionResult:
        """阶段1: LLM决策层"""
        try:
            # LLM选择DAG方案
            selection = await self.llm_decision_engine.select_dag_template(
                user_query, user_profile
            )
            
            logger.info(f"LLM选择模板: {selection.template_id}, 置信度: {selection.confidence}")
            return selection
            
        except Exception as e:
            logger.error(f"LLM决策失败: {e}, 降级到规则匹配")
            # 降级策略：规则匹配
            return self._fallback_rule_matching(user_query)
    
    async def _stage2_program_execution(
        self,
        dag_selection: DAGSelectionResult,
        user_profile: Dict[str, Any],
        context: Dict[str, Any]
    ) -> Dict[str, Any]:
        """阶段2: 程序执行层"""
        try:
            # 获取DAG模板
            template = self.template_manager.get_template(dag_selection.template_id)
            
            # 执行DAG
            tool_results = await self.dag_orchestrator.execute_dag(
                template,
                {"user_profile": user_profile, **context}
            )
            
            logger.info(f"DAG执行完成，调用了{len(tool_results)}个工具")
            return tool_results
            
        except Exception as e:
            logger.error(f"程序执行失败: {e}")
            raise
    
    async def _stage3_llm_synthesis(
        self,
        user_query: str,
        user_profile: Dict[str, Any],
        tool_results: Dict[str, Any],
        context: Dict[str, Any]
    ) -> str:
        """阶段3: LLM综合层"""
        try:
            # LLM深度分析
            ai_response = await self.llm_analysis_engine.analyze_and_synthesize(
                user_query, user_profile, tool_results
            )
            
            logger.info("LLM综合分析完成")
            return ai_response
            
        except Exception as e:
            logger.error(f"LLM综合失败: {e}")
            # 降级策略：简单翻译
            return self._fallback_simple_translation(tool_results)
```

## 核心优势

### 1. 避免LLM幻觉

```python
# ❌ 旧方式：LLM直接调用MCP工具
# LLM可能生成不存在的工具名或参数

# ✅ 新方式：三段式架构
# 阶段1: LLM只从预定义模板中选择
# 阶段2: 程序严格执行DAG
# 阶段3: LLM基于真实数据分析
```

### 2. 灵活扩展

```python
# 新增DAG模板无需修改LLM
new_template = DAGTemplate(...)
template_manager.register_template(new_template)

# LLM自动识别新模板
```

### 3. 降级策略

```python
# 阶段1失败 → 规则匹配
# 阶段2失败 → 抛出异常
# 阶段3失败 → 简单翻译
```
