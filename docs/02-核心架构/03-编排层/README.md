## 📋 模块说明

本模块包含DAML-RAG框架的编排层架构文档,负责任务编排、工具调用和执行流程控制。

编排层是连接LLM决策层和数据层的桥梁,通过DAG编排器和MCP工具实现:
- **任务编排**: 基于DAG模板的任务依赖管理和执行流程控制
- **工具调用**: 通过MCP协议调用18个专业健身工具（17个Python内置 + 1个stdio）
- **三段式架构**: LLM决策 → 程序执行 → LLM综合的完整流程
