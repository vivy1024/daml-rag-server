## 📋 概述

本文档记录前端用户档案选项与Neo4j节点的映射关系。

### v2.1.0 体态矫正更新

**新增内容**: 添加PosturalIssue（体态问题）映射，支持12个体态问题选项。

### v2.0.0 统一化更新

**核心变更**: 前端选项与Neo4j节点完全一致，不再需要复杂的映射转换。

| 字段 | v1.0.0 | v2.0.0 |
|------|--------|--------|
| 训练目标 | 需要映射（如"增肌"→["增肌","Gain Muscle"]） | 直接对应（中英文名称对照） |
| 器械 | 需要映射（如"杠铃"→["杠铃","杠铃片"]） | 直接对应（中英文名称对照） |
| 伤病 | 需要映射（如"腰部损伤"→["下背部疼痛","腰椎间盘突出"]） | 直接选择具体伤病 |

### 数据流向

```
前端选项 (yuzhen_fitness/src/types/user-profile.ts)
    ↓ 直接对应
后端存储 (yuzhen-backend/user_profiles表)
    ↓ 中英文转换
DAML-RAG查询 (user_profile_data_mapper.py)
    ↓ 英文name
Neo4j节点查询
```

### 映射服务位置

- **映射服务**: `daml-rag-server/src/applications/fitness/services/user_profile_data_mapper.py`
- **前端类型**: `yuzhen_fitness/src/types/user-profile.ts`
- **后端验证**: `yuzhen-backend/app/Modules/User/Requests/UpdateProfileRequest.php`


### 体态问题关系

PosturalIssue节点与其他节点的关系：

| 关系类型 | 方向 | 说明 | 状态 |
|---------|------|------|------|
| CORRECTS | Exercise → PosturalIssue | 矫正动作 | 待补充 |
| AGGRAVATES | Exercise → PosturalIssue | 加重动作 | 待补充 |
| RELATED_TO | PosturalIssue → Muscle | 相关肌肉 | ✅ 已建立（16个关系） |

### MCP工具使用

体态问题数据主要用于以下MCP工具：

1. **postural_assessor** - 体态评估工具
   - 识别用户体态问题
   - 推荐矫正动作（基于CORRECTS关系）
   - 警告加重动作（基于AGGRAVATES关系）
   - 提供相关肌肉信息（基于RELATED_TO关系）

2. **intelligent_exercise_selector** - 智能动作选择器
   - 根据体态问题过滤不适合的动作
   - 优先推荐矫正动作

3. **professional_program_designer** - 专业训练计划设计
   - 在训练计划中融入体态矫正动作
   - 避免加重体态问题的动作
