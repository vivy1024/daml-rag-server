## 📋 模块说明

本模块包含DAML-RAG框架的监控层架构文档，负责系统监控、日志记录和流式输出。

**重要变更（v2.0.0）**：监控层已完成简化，从13个文件（244KB）精简到5个核心模块（72KB），减少70%代码量，同时保持所有监控API和前端页面的完整功能。

### 简化后的监控架构

监控层现在只保留支持API接口所需的核心功能：
- **流式监控**: StreamingMetrics - 流式会话性能监控
- **指标收集**: MetricsCollector - 系统和应用指标收集
- **并发控制**: ConcurrencyLimiter - API并发限制和过载保护
- **结构化日志**: StructuredLogger - 统一的日志记录
- **Prometheus集成**: PrometheusIntegration - 指标导出和时序数据
