## 📋 文档说明

本文档详细说明DAML-RAG框架应用层（健身领域）的所有代码文件功能。应用层是框架层的具体实现，包含健身领域特定的业务逻辑、工具集成和工作流编排。

**应用层职责**：
- 实现健身领域特定的业务逻辑
- 集成23个专业健身MCP工具
- 实现三段式智能编排架构
- 提供完整的11步工作流程
- 管理健身领域的缓存和优化策略

### 2. three_stage_orchestrator.py - 三段式编排器（核心）

**功能**: 实现三段式智能架构的核心编排器

**三段式架构**:
```
阶段1：LLM决策 → 理解意图，选择DAG方案
阶段2：程序执行 → 执行DAG，三层检索，并行优化
阶段3：LLM综合 → 深度分析，专业建议，安全提醒
```

**核心特性**:
- ✅ 端到端工作流程集成
- ✅ LLM决策引擎调用
- ✅ DAG执行引擎调用
- ✅ LLM分析引擎调用
- ✅ 性能监控和统计
- ✅ 错误处理和降级策略

**主要类**:
- `ThreeStageOrchestrator`: 三段式编排器主类
- `ThreeStageRequest`: 编排请求数据结构
- `ThreeStageResult`: 编排结果数据结构

**关键方法**:
- `execute()`: 执行完整三段式工作流程
- `_stage1_llm_decision()`: 阶段1 - LLM决策
- `_stage2_dag_execution()`: 阶段2 - DAG执行
- `_stage3_llm_analysis()`: 阶段3 - LLM综合分析

**版本**: v1.0.0  
**代码行数**: ~400行  
**对应工作流程**: 步骤1-11完整集成

### 依赖关系
```
应用层 (applications/fitness/)
  ↓ 依赖
框架层 (framework/)
  ├── clients/          # 后端客户端、LLM客户端
```

## 📝 开发指南

### 添加新工具
1. 在`tools/`目录创建新工具文件
2. 继承`BaseMCPTool`基类
3. 实现`execute()`方法
4. 在`component_registrations.py`注册工具
5. 更新DAG模板（如需要）

### 添加新模板
1. 在`dag_template_system.py`中定义新模板
2. 指定必需工具和可选工具
3. 定义工具依赖关系
4. 定义并行组
5. 更新LLM决策引擎提示词

### 修改工作流程
1. 确定修改点（步骤1-11）
2. 修改对应的编排器方法
3. 更新性能监控
4. 更新文档
5. 添加测试
