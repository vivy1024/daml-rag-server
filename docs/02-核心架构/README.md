## 📋 概述

本目录包含DAML-RAG系统的核心架构设计文档，回答"是什么"和"为什么"的问题。文档按功能模块组织，涵盖系统架构、数据层、编排层、LLM层、监控层和优化层六大模块。

### 架构规模

- **代码文件**：172个Python文件（四层架构）
- **MCP工具**：18个（17个Python内置 + 1个stdio用户档案）
- **服务层**：16个业务逻辑组件
- **参数系统**：6个参数处理组件
