## 📋 模块说明

本模块包含 DAML-RAG v3.0 新增的检索优化组件。这些模块基于最新学术论文实现，显著提升检索质量和响应速度。

v3.0 优化层的核心职责：
- **检索融合**：多路检索结果的校准融合
- **图卷积重排**：基于图结构的无参数重排序
- **查询重塑**：向量空间中的查询优化
- **热数据缓存**：高频查询的内存化加速

---

## 📚 核心模块

### 1. CalibratedFusion（校准融合）

**文件**: `src/calibrated_fusion.py`
**论文**: PhaseGraph — 多阶段检索融合

将 Qdrant 向量检索、Neo4j 图检索、规则约束检索三路结果进行校准融合：
- 对每路检索结果进行分数校准（消除量纲差异）
- 基于置信度加权融合
- 动态调整各路权重（根据查询类型）

```
Vector Score (0-1) ──┐
Graph Score (0-1)  ──┼── Calibration ── Weighted Fusion ── Final Ranking
Rule Score (0-1)   ──┘
```

### 2. GraphConvRerank（图卷积重排序）

**文件**: `src/graph_conv_rerank.py`
**论文**: Non-parametric Graph Convolution Reranking

基于 Neo4j 知识图谱的拓扑结构对检索结果进行重排序：
- 无参数设计：不需要额外训练，直接利用图结构
- 邻居传播：通过图卷积聚合邻居节点信息
- 结构感知：考虑实体间的关系强度和路径距离

**适用场景**：
- 动作替换推荐（相似动作图谱）
- 肌群关联查询（协同/拮抗肌群）
- 训练计划关联（前置/后续训练）

### 3. QueryReshaper（查询重塑）

**文件**: `src/query_reshaper.py`

在向量空间中对用户查询进行重塑，提升检索召回率：
- 查询扩展：补充隐含的健身领域术语
- 向量偏移：将查询向量向目标语义空间偏移
- 多视角生成：从不同角度生成查询变体

**示例**：
```
原始查询: "肩膀疼怎么练"
重塑后:
  - "肩关节疼痛 训练替代方案"
  - "肩袖损伤 安全动作选择"
  - "三角肌训练 避免疼痛"
```

### 4. InMemoryHotCache（内存热数据缓存）

**文件**: `src/in_memory_hot_cache.py`

对高频查询结果进行内存化缓存，减少重复计算：
- LRU 淘汰策略
- TTL 过期机制
- 查询指纹去重（语义相似查询命中同一缓存）
- 与 Redis 缓存互补（Redis 做持久化，InMemory 做毫秒级响应）

**缓存层级**：
```
请求 → InMemoryHotCache (μs) → Redis Cache (ms) → 实际检索 (100ms+)
```
