## 🐳 Docker服务

### 服务配置

**文件**: `docker-compose.yml`

```yaml
services:
  # Neo4j图数据库
  neo4j:
    image: neo4j:5.15-community
    ports:
      - "7474:7474"  # Web UI
      - "7687:7687"  # Bolt
    environment:
      NEO4J_AUTH: neo4j/password
      NEO4J_PLUGINS: '["apoc"]'
      NEO4J_dbms_memory_heap_max__size: 1G
      NEO4J_dbms_memory_pagecache_size: 512M

  # Qdrant向量搜索
  qdrant:
    image: qdrant/qdrant:v1.15.1
    ports:
      - "6333:6333"
      - "6334:6334"

  # Redis缓存
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    command: redis-server --save 60 1 --appendonly yes
```

  - 账号: neo4j
  - 密码: password
- **Qdrant Dashboard**: http://localhost:6333/dashboard
- **DAML-RAG Server API**: http://localhost:8001/docs

## 🔧 配置示例

### Embedding配置

**文件**: `config_embedding.py`

```python
import torch

# Embedding类型选择
EMBEDDING_TYPE = "bge"  # "bge" 或 "random"

# BGE模型配置
BGE_MODEL = "BAAI/bge-base-zh-v1.5"
BGE_DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
BGE_USE_SAFETENSORS = True

# 向量维度
EMBEDDING_DIM = 768
```

### Neo4j配置

```python
NEO4J_URI = "bolt://localhost:7687"
NEO4J_USER = "neo4j"
NEO4J_PASSWORD = "password"
NEO4J_DATABASE = "neo4j"
```

### Qdrant配置

```python
QDRANT_HOST = "localhost"
QDRANT_PORT = 6333
QDRANT_COLLECTION = "fitness_kg"
QDRANT_VECTOR_SIZE = 768
```

## 📝 维护指南

### 启动服务

```bash
# 启动知识图谱服务
docker-compose up -d

# 检查服务状态
docker-compose ps
```

### 重建向量库（可选）

如果需要使用真实BGE向量替换随机向量：

```bash
python build_kg_full.py
```

### 故障排查

#### Neo4j连接失败

```bash
docker-compose restart neo4j
python tests/test_kg_queries.py
```

#### BGE模型加载失败

```bash
# 检查PyTorch
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"

# 重新测试
python tests/test_bge_workaround.py
```

#### GPU不可用

```bash
# 检查CUDA
nvidia-smi

# 如果没有GPU，模型自动切换到CPU
# BGE_DEVICE会自动设置为"cpu"
```
