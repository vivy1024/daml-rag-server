2. **MCP工具API参考.md** - MCP工具详细API（主文档）
3. **README.md** - 目录索引

**删除文档**:
1. ~~03-API接口参考.md~~ - 内容整合到主文档
2. ~~API_USAGE.md~~ - 使用示例整合到主文档
3. ~~MCP工具API.md~~ - 内容整合到MCP工具API参考.md

**整合步骤**:
1. 从 `03-API接口参考.md` 提取有价值内容：
   - 对话历史功能说明 → 整合到 `API参考文档.md`
   - ChatService实现细节 → 整合到代码参考文档
   - 监控系统API → 移动到监控层文档

2. 从 `API_USAGE.md` 提取有价值内容：
   - 快速开始示例 → 整合到 `API参考文档.md`
   - 使用示例代码 → 整合到 `API参考文档.md`

3. 从 `MCP工具API.md` 提取有价值内容：
   - MCP工具架构说明 → 整合到 `MCP工具API参考.md`
   - 工具调用方式 → 整合到 `MCP工具API参考.md`

---

### 方案B：保留三个文档

**保留文档**:
1. **API参考文档.md** - HTTP API接口参考
2. **API使用指南.md** - API使用示例和最佳实践
3. **MCP工具API参考.md** - MCP工具详细API

**优点**: 职责更清晰

## ✅ 推荐方案：方案A

**理由**:
1. 减少文档数量，降低维护成本
2. 避免内容重复和不一致
3. 用户查找更方便（只需查看2个主文档）
4. 符合"单一权威来源"原则

**实施步骤**:
1. ✅ 分析完成（本文档）
