## 📋 概述

本文档描述DAML-RAG系统的安全增强措施，包括输入验证、认证授权、数据加密、限流保护、安全日志等功能。

## 🔒 安全功能概览

### 1. 输入验证和清理

**功能**：验证和清理所有用户输入，防止注入攻击

**实现位置**：`src/api/middleware/security.py` - `InputValidator`

**主要特性**：
- XSS攻击防护
- SQL注入防护
- 路径遍历防护
- 模板注入防护
- 输入长度限制
- 危险字符过滤

**使用示例**：
```python
from src.api.middleware.security import InputValidator

# 验证单个字段
clean_query = InputValidator.validate_and_clean('query', user_input)

# 验证整个字典
clean_data = InputValidator.validate_dict(
    request_data,
    required_fields=['user_id', 'query']
)
```

**危险模式检测**：
- `<script>` 标签
- JavaScript协议
- 事件处理器（onclick等）
- iframe注入
- eval/exec函数
- 模板注入 `${}`
- 路径遍历 `../`
- SQL注入关键字

**字段长度限制**：
- query: 2000字符
- comment: 1000字符
- user_id: 100字符
- session_id: 100字符
- 默认: 500字符

### 2. 认证和授权

**功能**：API访问控制和用户身份验证

**实现位置**：`src/api/middleware/security.py` - `AuthenticationManager`

**认证模式**：
- Bearer Token认证
- 开发环境：可选认证（默认关闭）
- 生产环境：强制认证

**公开路径**（无需认证）：
- `/docs` - API文档
- `/redoc` - ReDoc文档
- `/openapi.json` - OpenAPI规范
- `/health` - 健康检查
- `/api/health` - API健康检查
- `/` - 根路径

**使用示例**：
```python
# 在请求头中添加认证令牌
headers = {
    'Authorization': 'Bearer your-token-here'
}

response = requests.post(
    'http://localhost:8001/api/v1/chat',
    headers=headers,
    json={'user_id': '123', 'query': '增肌计划'}
)
```

**环境配置**：
```bash
# .env文件
ENABLE_AUTH=false  # 开发环境：关闭认证
ENABLE_AUTH=true   # 生产环境：启用认证
```

### 3. 限流保护

**功能**：防止API滥用和DDoS攻击

**实现位置**：`src/api/middleware/security.py` - `RateLimiter`

**限流策略**：
- 每分钟限制：60次请求
- 每小时限制：1000次请求
- 突发限制：5秒内最多10次请求

**客户端识别**：
1. 优先使用用户ID（如果已认证）
2. 使用IP地址（从X-Forwarded-For或client.host）

**黑名单机制**：
- 超过每小时限制自动加入黑名单
- 黑名单持续时间：1小时
- 黑名单客户端所有请求被拒绝

**响应码**：
- 429 Too Many Requests - 超过限流
- 403 Forbidden - 黑名单客户端

**环境配置**：
```bash
# .env文件
ENABLE_RATE_LIMIT=true  # 启用限流
ENABLE_RATE_LIMIT=false # 关闭限流（仅开发环境）
```

### 4. 数据加密

**功能**：加密存储敏感数据

**实现位置**：`src/api/utils/encryption.py`

#### 4.1 加密管理器

**用途**：加密和解密敏感数据

```python
from src.api.utils.encryption import get_encryption_manager

# 获取加密管理器
encryptor = get_encryption_manager()

# 加密数据
encrypted = encryptor.encrypt("sensitive_data")

# 解密数据
decrypted = encryptor.decrypt(encrypted)

# 加密字典字段
user_data = {
    'user_id': '123',
    'email': 'user@example.com',
    'phone': '13800138000'
}
encrypted_data = encryptor.encrypt_dict(
    user_data,
    fields_to_encrypt=['email', 'phone']
)
```

**环境配置**：
```bash
# .env文件
ENCRYPTION_KEY=your-base64-encoded-key-here
```

**生成加密密钥**：
```python
from cryptography.fernet import Fernet
key = Fernet.generate_key()
print(key.decode())  # 保存到.env文件
```

#### 4.2 密码哈希

**用途**：安全存储用户密码

```python
from src.api.utils.encryption import get_password_hasher

hasher = get_password_hasher()

# 哈希密码
hashed_password, salt = hasher.hash_password("user_password")

# 验证密码
is_valid = hasher.verify_password(
    "user_password",
    hashed_password,
    salt
)
```

**算法**：PBKDF2-SHA256，100,000次迭代

#### 4.3 令牌生成

**用途**：生成安全的访问令牌和API密钥

```python
from src.api.utils.encryption import get_token_generator

generator = get_token_generator()

# 生成随机令牌
token = generator.generate_token(length=32)

# 生成API密钥
api_key = generator.generate_api_key(prefix="sk")

# 生成会话ID
session_id = generator.generate_session_id()
```

#### 4.4 数据脱敏

**用途**：在日志和响应中隐藏敏感信息

```python
from src.api.utils.encryption import get_data_masker

masker = get_data_masker()

# 脱敏邮箱
masked_email = masker.mask_email("user@example.com")
# 结果: u***@example.com

# 脱敏手机号
masked_phone = masker.mask_phone("13800138000")
# 结果: 138****8000

# 脱敏身份证号
masked_id = masker.mask_id_card("110101199001011234")
# 结果: 110***********1234

# 脱敏令牌
masked_token = masker.mask_token("sk-abc123def456", visible_chars=8)
# 结果: sk-abc12...

# 脱敏字典
user_data = {
    'email': 'user@example.com',
    'phone': '13800138000',
    'token': 'sk-abc123def456'
}
masked_data = masker.mask_dict(user_data, {
    'email': 'email',
    'phone': 'phone',
    'token': 'token'
})
```

### 5. 安全日志

**功能**：记录安全相关事件，不泄露敏感信息

**实现位置**：`src/api/middleware/security.py` - `SecurityLogger`

**敏感字段**（自动脱敏）：
- password
- token
- api_key
- secret
- authorization
- cookie

**日志类型**：
1. **请求日志**：记录所有API请求
2. **安全事件**：记录安全相关事件（认证失败、限流触发等）
3. **异常日志**：记录系统异常（不泄露内部信息）

**使用示例**：
```python
from src.api.middleware.security import SecurityLogger

# 记录请求
SecurityLogger.log_request(request, user_info)

# 记录安全事件
SecurityLogger.log_security_event(
    'authentication_failed',
    {'user_id': '123', 'reason': 'invalid_token'}
)
```

**日志格式**：
```json
{
    "timestamp": "2025-12-16T10:30:00",
    "event_type": "api_request",
    "method": "POST",
    "path": "/api/v1/chat",
    "client": "192.168.1.100",
    "user_id": "123",
    "user_agent": "Mozilla/5.0..."
}
```

### 6. 错误处理安全

**功能**：安全的错误响应，不泄露系统内部信息

**实现**：
- 生产环境：返回通用错误消息
- 开发环境：返回详细错误信息（DEBUG=true）
- 所有异常都被捕获和记录
- 敏感信息自动脱敏

**错误响应格式**：
```json
{
    "code": 500,
    "msg": "服务器内部错误",
    "data": null
}
```

**开发环境错误响应**（DEBUG=true）：
```json
{
    "code": 500,
    "msg": "服务器内部错误",
    "data": {
        "error": "详细错误信息..."
    }
}
```

## 🔧 配置指南

### 环境变量配置

在 `.env` 文件中配置安全选项：

```bash
# ============= 安全配置 =============

# 启用限流保护
ENABLE_RATE_LIMIT=true

# 启用认证（生产环境建议启用）
ENABLE_AUTH=false

# 启用输入验证
ENABLE_INPUT_VALIDATION=true

# 加密密钥（必须设置，用于加密敏感数据）
ENCRYPTION_KEY=your-base64-encoded-key-here

# 调试模式（生产环境必须设置为false）
DEBUG=false

# 环境类型
ENVIRONMENT=development  # 或 production
```

## 🛡️ 安全最佳实践

### 1. 输入验证

**原则**：永远不要信任用户输入

**实践**：
- 所有用户输入必须验证和清理
- 使用白名单而非黑名单
- 限制输入长度
- 验证数据类型和格式

### 2. 认证和授权

**原则**：最小权限原则

**实践**：
- 使用强密码策略
- 实现令牌刷新机制
- 定期轮换API密钥
- 记录所有认证事件

### 3. 数据保护

**原则**：数据加密和脱敏

**实践**：
- 敏感数据加密存储
- 传输使用HTTPS
- 日志中脱敏敏感信息
- 定期备份加密密钥

### 4. 限流和防护

**原则**：防止滥用和攻击

**实践**：
- 实施多层限流策略
- 使用IP黑名单
- 监控异常流量
- 配置DDoS防护

### 5. 日志和监控

**原则**：可观测性和可追溯性

**实践**：
- 记录所有安全事件
- 不记录敏感信息
- 使用结构化日志
- 配置实时告警

### 6. 错误处理

**原则**：安全的错误响应

**实践**：
- 不泄露系统内部信息
- 使用通用错误消息
- 详细错误记录到日志
- 区分开发和生产环境

## 📊 安全监控

### 监控指标

1. **认证失败率**
   - 指标：失败次数/总请求数
   - 告警阈值：> 5%

2. **限流触发率**
   - 指标：被限流请求数/总请求数
   - 告警阈值：> 10%

3. **异常错误率**
   - 指标：5xx错误数/总请求数
   - 告警阈值：> 1%

4. **黑名单客户端数**
   - 指标：黑名单中的客户端数量
   - 告警阈值：> 10

### 日志分析

**关键日志事件**：
- 认证失败
- 限流触发
- 输入验证失败
- 异常错误
- 黑名单添加

**日志查询示例**：
```bash
# 查看认证失败日志
grep "authentication_failed" /var/log/daml-rag/security.log

# 查看限流触发日志
grep "rate_limit_exceeded" /var/log/daml-rag/security.log

# 查看异常错误日志
grep "unexpected_exception" /var/log/daml-rag/security.log
```

## 🔍 安全测试

### 输入验证测试

```python
import requests

# 测试XSS防护
response = requests.post(
    'http://localhost:8001/api/v1/chat',
    json={
        'user_id': '123',
        'query': '<script>alert("XSS")</script>'
    }
)
assert response.status_code == 400

# 测试SQL注入防护
response = requests.post(
    'http://localhost:8001/api/v1/chat',
    json={
        'user_id': '123',
        'query': "'; DROP TABLE users; --"
    }
)
assert response.status_code == 400
```

### 限流测试

```python
import requests
import time

# 测试每分钟限流
for i in range(70):
    response = requests.post(
        'http://localhost:8001/api/v1/chat',
        json={'user_id': '123', 'query': f'测试{i}'}
    )
    if i < 60:
        assert response.status_code == 200
    else:
        assert response.status_code == 429
    time.sleep(0.5)
```

### 认证测试

```python
import requests

# 测试无令牌访问
response = requests.post(
    'http://localhost:8001/api/v1/chat',
    json={'user_id': '123', 'query': '测试'}
)
# 开发环境：200，生产环境：401

# 测试无效令牌
response = requests.post(
    'http://localhost:8001/api/v1/chat',
    headers={'Authorization': 'Bearer invalid-token'},
    json={'user_id': '123', 'query': '测试'}
)
# 生产环境：401
```
