## 2. 智能缓存管理

### 2.1 多层缓存架构

智能缓存管理器（`IntelligentCacheManager`）提供了统一的多层缓存解决方案：

```
L1 内存缓存 (快速访问, <50ms)
  ↓ 未命中
L2 Redis缓存 (持久化, <100ms)
  ↓ 未命中
L3 数据库 (实时计算, <500ms)
```

**核心特性**：
- LRU淘汰策略
- 自动TTL管理
- 缓存回填机制
- 降级策略（Redis不可用时自动降级到内存缓存）

### 2.2 配置说明

**配置位置**: `config/performance_optimization.yaml` → `cache`

```yaml
cache:
  # L1内存缓存
  l1_enabled: true
  l1_max_size: 1000              # 最大条目数
  l1_max_memory_mb: 100          # 最大内存占用(MB)
  
  # L2 Redis缓存
  l2_enabled: true
  l2_host: "localhost"
  l2_port: 6379
  l2_db: 0
  
  # 默认TTL
  default_ttl: 300               # 5分钟
  
  # 预热配置
  warmup_enabled: true
  warmup_batch_size: 10
```

### 2.3 使用方法

#### 基本使用

```python
from src.framework.storage import IntelligentCacheManager, CacheConfig

# 创建缓存管理器
cache_manager = IntelligentCacheManager(
    config=cache_config,
    redis_client=redis_client
)

# 存储数据
await cache_manager.put("user:123:profile", user_profile, ttl=3600)

# 获取数据
profile = await cache_manager.get("user:123:profile")
```

#### 带fetch函数的使用

```python
# 定义数据获取函数
async def fetch_user_profile():
    return await database.get_user_profile(user_id)

# 获取数据（自动缓存）
profile = await cache_manager.get(
    key="user:123:profile",
    fetch_func=fetch_user_profile,
    ttl=3600
)
```

#### 缓存失效

```python
# 精确失效
await cache_manager.invalidate("user:123:profile")

# 模式失效
await cache_manager.invalidate("user:123:*", pattern=True)
```

#### 缓存预热

```python
# 预热多个键
keys = ["user:1:profile", "user:2:profile", "user:3:profile"]
await cache_manager.warm_up(keys, fetch_data)
```

## 3. 连接池管理

### 3.1 概述

连接池管理器统一管理MySQL、Neo4j和HTTP连接池，提供连接复用、健康检查和动态调整功能。

### 3.2 配置说明

**配置位置**: `config/performance_optimization.yaml` → `connection_pool`

```yaml
connection_pool:
  mysql:
    min_size: 10                # 最小连接数
    max_size: 50                # 最大连接数
    max_idle_time: 60           # 最大空闲时间（秒）
    acquire_timeout: 2          # 获取连接超时（秒）
  neo4j:
    min_size: 5
    max_size: 20
    max_idle_time: 60
    acquire_timeout: 2
  http:
    min_size: 20
    max_size: 100
    max_idle_time: 30
    acquire_timeout: 2
```

### 3.3 使用方法

```python
from src.framework.storage.connection_pool_manager import ConnectionPoolManager

# 初始化连接池管理器
pool_manager = ConnectionPoolManager(
    mysql_config=config['connection_pool']['mysql'],
    neo4j_config=config['connection_pool']['neo4j'],
    http_config=config['connection_pool']['http']
)

# 获取MySQL连接
async with pool_manager.get_mysql_connection() as conn:
    result = await conn.execute("SELECT * FROM users WHERE id = ?", (user_id,))

# 获取Neo4j连接
async with pool_manager.get_neo4j_connection() as conn:
    result = await conn.run("MATCH (n) RETURN n LIMIT 10")

# 健康检查
health_status = await pool_manager.health_check()
```

## 常见问题

### Q1: 如何禁用Redis缓存？

```yaml
cache:
  l2_enabled: false
```

### Q2: 如何调整并发限制？

```yaml
concurrency:
  max_concurrent: 200  # 调整为200
```

### Q3: 如何更改LLM超时时间？

```yaml
llm_fallback:
  timeout: 60  # 调整为60秒
```

### Q4: 如何启用Prometheus监控？

```yaml
monitoring:
  prometheus:
    enabled: true
    port: 9090
```

### Q5: 如何查看性能瓶颈？

访问Grafana仪表板: http://localhost:3001

查看"工作流性能总览"仪表板，识别耗时最长的步骤。

### Q6: 如何优化TTFB？

1. 启用缓存: `cache.l1_enabled: true`
2. 优化步骤1-2并行执行
3. 优化步骤3-4并行执行
4. 减少BGE分类耗时: `bge_classification.max_query_length: 500`

### Q7: 如何提高缓存命中率？

1. 合理设置TTL（不要太短）
2. 使用缓存预热
3. 增加L1缓存容量
4. 优化缓存键设计

### Q8: 如何选择合适的缓存层级？

根据数据特性选择：
- **L1内存**：频繁访问、小数据量、对速度要求极高
- **L2 Redis**：重要数据、需要持久化、多实例共享
- **L3数据库**：大数据量、不常访问、需要完整性
