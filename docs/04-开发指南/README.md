## 🚀 学习路径建议

### 新手入门路径（1-2天）
1. **第一步**：阅读 [01-快速上手/01-DAG模板开发指南.md](./01-快速上手/01-DAG模板开发指南.md)
   - 了解DAG模板的基本概念
   - 学习如何创建简单的DAG模板
   
2. **第二步**：阅读 [01-快速上手/02-MCP工具开发指南.md](./01-快速上手/02-MCP工具开发指南.md)
   - 了解MCP工具的开发规范
   - 学习如何创建自定义MCP工具
   
3. **第三步**：阅读 [01-快速上手/03-三层检索使用指南.md](./01-快速上手/03-三层检索使用指南.md)
   - 了解三层检索的工作原理
   - 学习如何使用三层检索API

### 工具使用路径（2-3天）
1. **DAG模板选择**：阅读 [02-工具使用/01-DAG模板选择指南.md](./02-工具使用/01-DAG模板选择指南.md)
   - 学习如何根据场景选择合适的DAG模板
   - 了解各模板的适用场景和配置方法
   
2. **MCP工具使用**：阅读 [02-工具使用/02-MCP工具使用指南.md](./02-工具使用/02-MCP工具使用指南.md) 和 [03-MCP工具功能清单.md](./02-工具使用/03-MCP工具功能清单.md)
   - 学习如何调用MCP工具
   - 了解所有可用的MCP工具功能
   
3. **流式输出**：阅读 [02-工具使用/04-流式输出使用指南.md](./02-工具使用/04-流式输出使用指南.md)
   - 学习如何使用SSE流式输出API
   - 了解前端集成方法

### 配置管理路径（1-2天）
1. **LLM配置**：阅读 [03-配置管理/01-LLM模板配置指南.md](./03-配置管理/01-LLM模板配置指南.md) 和 [02-LLM响应配置管理器使用指南.md](./03-配置管理/02-LLM响应配置管理器使用指南.md)
   - 学习如何配置LLM决策模板和分析模板
   - 了解LLM响应配置管理器的使用方法
   
2. **API配置**：阅读 [03-配置管理/03-DeepSeek-API调用指南.md](./03-配置管理/03-DeepSeek-API调用指南.md)
   - 学习DeepSeek API的调用规范
   
3. **性能配置**：阅读 [03-配置管理/04-性能优化配置使用指南.md](./03-配置管理/04-性能优化配置使用指南.md)
   - 学习如何配置性能优化参数

### 最佳实践路径（3-5天）
1. **监控系统**：阅读 [04-最佳实践/01-监控和可观测性完整指南.md](./04-最佳实践/01-监控和可观测性完整指南.md)
   - 学习如何配置监控系统
   - 了解日志、指标、告警的最佳实践
   
2. **性能优化**：阅读 [04-最佳实践/02-性能优化完整指南.md](./04-最佳实践/02-性能优化完整指南.md)
   - 学习缓存、连接池、并发优化方法
   - 了解工作流性能优化策略
   
3. **安全性**：阅读 [04-最佳实践/03-安全性增强指南.md](./04-最佳实践/03-安全性增强指南.md)
   - 学习安全配置和最佳实践
   
4. **质量保证**：阅读 [04-最佳实践/04-质量保证与专家验证体系.md](./04-最佳实践/04-质量保证与专家验证体系.md)
   - 了解质量保证机制和专家验证流程

### Grafana运维路径（2-3天）
1. **日志分析**：阅读 [04-最佳实践/05-Grafana日志查询和分析指南.md](./04-最佳实践/05-Grafana日志查询和分析指南.md)
   - 学习Grafana Loki日志查询
   - 了解日志可视化面板配置
   
2. **告警配置**：阅读 [04-最佳实践/06-Grafana告警配置和响应指南.md](./04-最佳实践/06-Grafana告警配置和响应指南.md)
   - 学习Grafana告警规则配置
   - 了解告警响应流程
   
3. **性能排查**：阅读 [04-最佳实践/07-Grafana性能问题排查指南.md](./04-最佳实践/07-Grafana性能问题排查指南.md)
   - 学习Grafana性能Dashboard分析
   - 了解性能问题排查方法
