## 二、体态评估与矫正（~500 chunks）

### 2.1 常见体态异常（~200）
每种体态问题需要覆盖：
- 外观表现（什么样子）
- 解剖学原因（哪些肌肉紧张/薄弱）
- 评估方法（如何判断严重程度）
- 矫正方案（拉伸+强化+日常习惯）
- 训练中的注意事项

具体体态问题：
- 上交叉综合征（圆肩+头前伸+驼背）
- 下交叉综合征（骨盆前倾+腰椎过度前凸）
- 膝内翻/膝外翻（X型腿/O型腿）
- 扁平足/高弓足
- 脊柱侧弯
- 翼状肩胛
- 骨盆不等高
- 足外翻/足内翻

### 2.2 肌肉失衡模式（~150）
- 上肢：胸大肌紧张 vs 菱形肌薄弱
- 下肢：髂腰肌紧张 vs 臀大肌薄弱
- 核心：腹直肌主导 vs 深层核心失活
- 每种失衡的：表现→原因→测试→矫正

### 2.3 异常肌肉形态（~150）
- 肌肉萎缩（废用性/神经性）的外观特征
- 肌肉痉挛/挛缩的识别
- 肌肉代偿肥大（如斜方肌上束代偿）
- 肌肉不对称（左右差异）的评估与纠正
- 常见的"假性肥大"（脂肪堆积 vs 真正肌肉增长）

## 生成格式

每个 chunk 应包含：
```json
{
  "source": "ai_knowledge_base",
  "category": "anatomy|posture|rehabilitation|methodology|nutrition|recovery|warmup",
  "subcategory": "具体子类",
  "title": "知识点标题",
  "content": "详细内容（200-500字/chunk）",
  "keywords": ["关键词1", "关键词2"],
  "confidence": "high|medium",
  "citation_note": "基于运动科学共识，无具体文献引用",
  "language": "zh",
  "related_muscles": ["相关肌群"],
  "related_injuries": ["相关伤病"],
  "related_exercises": ["相关动作"]
}
```

## 生成策略

1. **按优先级分批生成**：P0 先做（解剖+体态+康复），这些是当前 Skill 最缺的
2. **每批生成后导入向量库**：用现有的 embedding pipeline（gte-large-zh）
3. **标注来源**：所有 AI 生成的知识标注 `source: "ai_knowledge_base"`，与教材来源区分
4. **交叉验证**：关键数据（如康复时间线、禁忌症）应与图谱数据交叉验证
5. **持续补充**：后续获取真实教材后，用教材内容替换/补充 AI 生成的内容

## 与图谱的关系

生成的知识应该能增强图谱的以下关系：
- `CONTRAINDICATED_FOR`：补充禁忌原因的详细解释
- `CORRECTS` / `AGGRAVATES`：补充体态矫正的机制解释
- `TARGETS_PRIMARY/SECONDARY`：补充肌肉功能解剖学背景
- `HAS_PHASE`：补充康复阶段的详细协议

知识向量用于语义搜索（search_knowledge），图谱关系用于确定性查询（get_contraindications）。两者互补。
