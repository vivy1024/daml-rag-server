## 1. 当前检索流程概述

### 1.1 三层检索架构

当前系统采用三层检索引擎 (`true_three_layer_engine.py`)，配合 GraphRAG 统一入口 (`graphrag.py`) 提供检索能力：

```
用户查询
  ↓
Layer 1: Qdrant 向量检索（语义相似度）
  ↓
Layer 2: Neo4j 图推理（结构化关系）
  ↓
Layer 3: 业务规则约束（安全/领域规则）
  ↓
结果合并 → 置信度加权 → 最终输出
```

**置信度权重分配**：L1: 0.3 | L2: 0.4 | L3: 0.3

### 1.2 核心文件与职责

| 文件 | 行数 | 职责 |
|------|------|------|
| `src/framework/retrieval/true_three_layer_engine.py` | 1674 | 三层引擎主体，编排 L1/L2/L3 |
| `src/framework/retrieval/graphrag.py` | 755 | GraphRAG 统一查询接口，Cypher 构建 |

### 2.1 新增知识节点类型

Phase 2 KG Pipeline 引入 5 种知识节点（来自教材提取）：

| 节点类型 | 说明 | 示例 |
|---------|------|------|
| `Concept` | 运动科学概念 | 超补偿、渐进超负荷 |
| `Principle` | 训练原则 | FITT原则、特异性原则 |
| `Mechanism` | 生理机制 | 肌肉肥大机制、能量系统 |
| `Guideline` | 权威指南 | ACSM力量训练指南 |
| `ResearchFinding` | 研究发现 | 最佳训练频率研究 |

### 2.2 跨域关系（已在 Schema 中定义）

`kg_extraction_schema.yaml` 已定义 4 种跨域关系：

| 关系 | 方向 | 说明 |
|------|------|------|
| `APPLIES_TO_EXERCISE` | Principle/Guideline → Exercise | 原则应用于动作 |
| `AFFECTS_MUSCLE` | Mechanism/Concept → Muscle | 机制影响肌肉 |
| `RECOMMENDED_BY` | Exercise ← Guideline | 动作被指南推荐 |
| `EXPLAINED_BY` | Exercise ← Concept/Mechanism | 动作原理解释 |

## 3. 新增 Cypher 查询模板

以下模板需添加到 `domain_adapter.get_cypher_templates()` 返回值中。

### 3.1 Concept 概念查询

```cypher
// knowledge_concept_search
MATCH (c:Concept)
WHERE c.name CONTAINS $query OR c.definition CONTAINS $query
OPTIONAL MATCH (c)-[:EXPLAINS]->(m:Mechanism)
OPTIONAL MATCH (c)-[:AFFECTS_MUSCLE]->(mu:Muscle)
OPTIONAL MATCH (c)<-[:BASED_ON]-(p:Principle)
RETURN c.name AS name, c.definition AS definition, c.category AS category,
       collect(DISTINCT m.name) AS related_mechanisms,
       collect(DISTINCT mu.name_zh) AS affected_muscles,
       collect(DISTINCT p.name) AS based_principles
LIMIT $limit
```

### 3.2 Principle 原则查询

```cypher
// knowledge_principle_search
MATCH (p:Principle)
WHERE p.name CONTAINS $query OR p.description CONTAINS $query
OPTIONAL MATCH (p)-[:APPLIES_TO_EXERCISE]->(e:Exercise)
OPTIONAL MATCH (p)-[:BASED_ON]->(c:Concept)
OPTIONAL MATCH (p)<-[:SUPPORTS]-(r:ResearchFinding)
RETURN p.name AS name, p.description AS description,
       p.application AS application, p.evidence_level AS evidence_level,
       collect(DISTINCT e.name_zh) AS applicable_exercises,
       collect(DISTINCT c.name) AS base_concepts,
       collect(DISTINCT r.title) AS supporting_research
LIMIT $limit
```

### 3.3 Mechanism 机制查询

```cypher
// knowledge_mechanism_search
MATCH (m:Mechanism)
WHERE m.name CONTAINS $query OR m.description CONTAINS $query
OPTIONAL MATCH (m)-[:AFFECTS_MUSCLE]->(mu:Muscle)
OPTIONAL MATCH (c:Concept)-[:EXPLAINS]->(m)
OPTIONAL MATCH (m)-[:EXPLAINED_BY]->(e:Exercise)
RETURN m.name AS name, m.description AS description,
       m.physiological_basis AS physiological_basis,
       m.time_course AS time_course,
       collect(DISTINCT mu.name_zh) AS affected_muscles,
       collect(DISTINCT c.name) AS explaining_concepts,
       collect(DISTINCT e.name_zh) AS related_exercises
LIMIT $limit
```

### 3.4 Guideline 指南查询

```cypher
// knowledge_guideline_search
MATCH (g:Guideline)
WHERE g.name CONTAINS $query OR g.recommendations CONTAINS $query
OPTIONAL MATCH (g)-[:RECOMMENDS]->(target)
OPTIONAL MATCH (g)-[:APPLIES_TO_EXERCISE]->(e:Exercise)
OPTIONAL MATCH (e)<-[:RECOMMENDED_BY]-(g)
RETURN g.name AS name, g.organization AS organization,
       g.year AS year, g.target_population AS target_population,
       g.recommendations AS recommendations,
       collect(DISTINCT e.name_zh) AS recommended_exercises
LIMIT $limit
```

### 3.5 ResearchFinding 研究查询

```cypher
// knowledge_research_search
MATCH (r:ResearchFinding)
WHERE r.title CONTAINS $query OR r.finding CONTAINS $query
OPTIONAL MATCH (r)-[:SUPPORTS]->(target)
OPTIONAL MATCH (r)-[:CONTRADICTS]->(other:ResearchFinding)
RETURN r.title AS title, r.finding AS finding,
       r.study_design AS study_design, r.sample_size AS sample_size,
       r.year AS year, r.authors AS authors,
       collect(DISTINCT other.title) AS contradicting_studies
LIMIT $limit
```

### 3.6 跨域联合查询（高级）

```cypher
// knowledge_cross_domain_search
// 从动作出发，查找相关的所有知识节点
MATCH (e:Exercise)
WHERE e.name_zh CONTAINS $query
OPTIONAL MATCH (e)<-[:APPLIES_TO_EXERCISE]-(p:Principle)
OPTIONAL MATCH (e)<-[:RECOMMENDED_BY]-(g:Guideline)
OPTIONAL MATCH (e)<-[:EXPLAINED_BY]-(c:Concept)
OPTIONAL MATCH (e)<-[:EXPLAINED_BY]-(m:Mechanism)
RETURN e.name_zh AS exercise_name,
       collect(DISTINCT {type: 'Principle', name: p.name, desc: p.description}) AS principles,
       collect(DISTINCT {type: 'Guideline', name: g.name, org: g.organization}) AS guidelines,
       collect(DISTINCT {type: 'Concept', name: c.name, def: c.definition}) AS concepts,
       collect(DISTINCT {type: 'Mechanism', name: m.name, desc: m.description}) AS mechanisms
LIMIT $limit
```

## 4. BGE-Reranker 集成方案

### 4.1 架构位置

```
L1 向量结果 ─┐
L2 图推理结果 ─┼─→ 结果合并 → 【BGE-Reranker】→ 置信度计算 → 最终输出
L3 规则结果 ─┘
```

### 4.2 插入点

**文件**: `true_three_layer_engine.py`
**方法**: `_build_final_result()` (line 1586)
**位置**: 结果选择（line ~1608）之后，置信度计算（line ~1610）之前

### 4.3 实现方案

```python
class TrueThreeLayerEngine:
    def __init__(self, ...):
        # 新增：Reranker 配置
        self.reranker_enabled = config.get("reranker_enabled", False)
        self.reranker_model = config.get("reranker_model", "BAAI/bge-reranker-v2-m3")
        self.reranker_top_k = config.get("reranker_top_k", 10)
        self._reranker = None  # 延迟加载

    @property
    def reranker(self):
        """延迟加载 BGE-Reranker，避免启动时开销"""
        if self._reranker is None and self.reranker_enabled:
            from FlagEmbedding import FlagReranker
            self._reranker = FlagReranker(
                self.reranker_model,
                use_fp16=True  # 半精度推理，降低显存
            )
        return self._reranker

    async def _rerank_results(self, query: str, results: list) -> list:
        """使用 BGE-Reranker 对合并结果重排序"""
        if not self.reranker or len(results) <= 1:
            return results

        # 构建 query-passage pairs
        pairs = []
        for r in results:
            passage = r.get("content", "") or r.get("description", "") or str(r)
            pairs.append([query, passage])

        # 计算 reranker scores
        scores = self.reranker.compute_score(pairs, normalize=True)
        if isinstance(scores, float):
            scores = [scores]

        # 按 reranker score 重排
        scored_results = list(zip(results, scores))
        scored_results.sort(key=lambda x: x[1], reverse=True)

        # 注入 reranker_score 到结果中
        reranked = []
        for result, score in scored_results[:self.reranker_top_k]:
            result["reranker_score"] = round(score, 4)
            reranked.append(result)

        return reranked
```

### 4.4 配置项

在 `.env` 中新增：

```env
# BGE-Reranker 配置
RERANKER_ENABLED=false          # 默认关闭，按需开启
RERANKER_MODEL=BAAI/bge-reranker-v2-m3
RERANKER_TOP_K=10               # Rerank 后保留的最大结果数
RERANKER_USE_FP16=true          # 半精度推理
```

### 4.5 降级策略

- Reranker 模型加载失败 → 跳过重排序，使用原始排序
- 推理超时（>500ms）→ 降级为原始排序
- 显存不足 → 自动切换 CPU 推理

## 5. 风险评估

### 5.1 性能风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| 知识节点 Cypher 查询慢 | L2 延迟增加 | 为 Concept/Principle 等节点建立 name 索引 |
| BGE-Reranker 推理延迟 | 整体响应变慢 50-200ms | 延迟加载 + FP16 + 超时降级 |
| 知识节点数量增长 | 查询结果膨胀 | LIMIT 控制 + Reranker 筛选 |

### 5.2 兼容性风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| domain_adapter 模板键冲突 | 现有查询被覆盖 | 新模板使用 `knowledge_` 前缀命名空间 |
| 结果格式不一致 | 下游处理报错 | 知识节点结果统一转换为标准 `RetrievalResult` |
| Neo4j 索引缺失 | 全表扫描 | 部署前执行索引创建脚本 |

### 5.3 数据质量风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| 教材提取质量不稳定 | 知识节点噪声大 | KG Pipeline 质量评分 + 低分过滤 |
| 跨域关系错误 | 误导用户 | 人工抽检 + 置信度阈值 |
| 节点属性缺失 | 查询结果不完整 | required 字段校验 + 默认值填充 |
