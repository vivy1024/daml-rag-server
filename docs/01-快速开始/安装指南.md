## 📋 最低配置要求

### 开发环境

| 组件 | 最低配置 | 推荐配置 | 说明 |
|-----|---------|---------|------|
| **CPU** | 4核 (i5-8代/Ryzen 5 3600) | 8核 (i7-10代/Ryzen 7 5800X) | 支持AVX2指令集 |
| **内存** | 16GB DDR4 | 32GB DDR4 | Anthropic Claude需要8GB |
| **磁盘** | 100GB SSD | 256GB NVMe SSD | 读写速度>500MB/s |
| **显卡** | 集成显卡 | NVIDIA RTX 3060+ (12GB) | 可选，BGE加速 |
| **网络** | 10Mbps | 100Mbps | 下载模型需要 |

### 生产环境

| 组件 | 最低配置 | 推荐配置 | 说明 |
|-----|---------|---------|------|
| **CPU** | 8核16线程 | 16核32线程 | 服务器级CPU |
| **内存** | 32GB ECC | 64GB+ ECC | 支持错误校验 |
| **磁盘** | 512GB NVMe | 1TB+ NVMe RAID | 企业级SSD |
| **显卡** | 无 | NVIDIA A100/H100 | AI推理加速 |
| **网络** | 100Mbps | 1Gbps+ | 低延迟 |

**⚠️ 强制要求**：
- 内存必须≥16GB（低于会导致Anthropic Claude OOM崩溃）
- 磁盘必须≥100GB可用空间（Docker需要）
- CPU必须≥4核（低于会导致推理超时）

## 🔧 安装步骤

### 1. 检查硬件资源

#### Windows PowerShell
```powershell
# 检查可用磁盘空间（需要≥100GB）
Get-PSDrive C | Select-Object Used,Free

# 检查内存（需要≥16GB）
Get-WmiObject Win32_ComputerSystem | Select-Object TotalPhysicalMemory

# 检查CPU核心数（需要≥4核）
Get-WmiObject Win32_Processor | Select-Object NumberOfCores,NumberOfLogicalProcessors
```

#### Linux/macOS
```bash
# 检查磁盘空间
df -h | grep -E '^Filesystem|/$'

# 检查内存
free -h

# 检查CPU
lscpu | grep -E 'CPU\(s\)|Model name'
```

**如果硬件不满足要求，停止安装并升级硬件！**

---

### 2. 安装Docker

#### Windows（推荐：Docker Desktop）

1. **下载Docker Desktop**
   - 官方地址：https://www.docker.com/products/docker-desktop/
   - 国内镜像：https://mirrors.tuna.tsinghua.edu.cn/docker-ce/

2. **安装要求**
   - 启用WSL 2（Windows Subsystem for Linux）
   - 启用Hyper-V虚拟化（Windows 10 Pro+）
   - BIOS开启虚拟化（Intel VT-x / AMD-V）

3. **安装步骤**
   ```powershell
   # 安装WSL 2（以管理员身份运行PowerShell）
   wsl --install
   wsl --set-default-version 2

   # 重启电脑后，运行Docker Desktop安装程序
   # 安装完成后验证
   docker --version
   docker-compose version
   ```

4. **配置Docker Desktop**
   - 打开Docker Desktop设置（Settings）
   - Resources → 内存设置为 16GB+
   - Resources → CPU设置为 4核+
   - Resources → 磁盘限制设置为 100GB+

#### Linux（推荐：Ubuntu/Rocky）

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# Rocky Linux/RHEL
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf install docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动Docker
sudo systemctl start docker
sudo systemctl enable docker

# 验证安装
docker --version
docker compose version
```

#### macOS

```bash
# 下载Docker Desktop for Mac
# https://www.docker.com/products/docker-desktop/

# 或使用Homebrew
brew install --cask docker

# 启动Docker Desktop后验证
docker --version
docker compose version
```

## 🐛 常见问题

### Q1: Docker安装失败 - 虚拟化未启用

**症状**：
```
Hardware assisted virtualization and data execution protection 
must be enabled in the BIOS
```

**解决**：
1. 重启电脑进入BIOS设置
2. 找到并启用：
   - Intel: Intel VT-x
   - AMD: AMD-V / SVM Mode
3. 保存设置并重启

### Q2: WSL 2安装失败（Windows）

**症状**：
```
WSL 2 installation is incomplete
```

**解决**：
```powershell
# 以管理员身份运行PowerShell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 重启电脑

# 下载并安装WSL 2内核更新包
# https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi

# 设置WSL 2为默认版本
wsl --set-default-version 2
```

### Q3: Anthropic Claude模型下载失败

**症状**：
```
Error: failed to pull model: connection timeout
```

**解决**：
```bash
# 方案A：使用代理
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
anthropic-claude pull qwen3:8b

# 方案B：从镜像站下载
# 1. 下载模型文件到本地
# 2. 使用 anthropic-claude create 导入

# 方案C：使用更小的模型
anthropic-claude pull qwen2.5:3b  # 仅需3GB内存
```

### Q4: 磁盘空间不足

**症状**：
```
Error response from daemon: no space left on device
```

**解决**：
```bash
# 清理Docker未使用资源
docker system prune -a  # 清理镜像和容器
docker volume prune     # 清理未使用的卷

# 移动Docker数据目录（Windows）
# Docker Desktop → Settings → Resources → Disk image location
# 改为其他盘符（如 D:\docker_data）

# 移动Docker数据目录（Linux）
sudo systemctl stop docker
sudo mv /var/lib/docker /new/path/docker
sudo ln -s /new/path/docker /var/lib/docker
sudo systemctl start docker
```

### Q5: 内存不足导致Anthropic Claude崩溃

**症状**：
```
Anthropic Claude exited with code 137 (OOM killed)
```

**解决**：
```bash
# 方案A：增加物理内存（推荐）

# 方案B：使用更小的模型
anthropic-claude pull qwen2.5:3b  # 3GB内存
anthropic-claude pull phi3:mini   # 2GB内存

# 方案C：调整Docker内存限制
# Docker Desktop → Settings → Resources → Memory
# 设置为至少16GB

# 方案D：关闭其他占用内存的程序
```
