## 🗄️ MySQL 8.4 配置

### 默认配置（docker-compose.yml）

```yaml
mysql:
  image: mysql:8.4
  container_name: fitness_mysql
  restart: unless-stopped
  ports:
    - "3306:3306"
  environment:
    MYSQL_DATABASE: fitness_app
    MYSQL_ROOT_PASSWORD: password
    MYSQL_USER: fitness_user
    MYSQL_PASSWORD: fitness_pass
  volumes:
    - mysql_data:/var/lib/mysql
  command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
```

### 资源配置

**内存占用**：1-2GB
- 初始化：800MB
- 正常运行：1.2GB
- 高并发：1.8GB

**磁盘占用**：8.2GB
- 数据文件：6.5GB
- 日志文件：1.2GB
- 临时文件：500MB

**CPU使用**：5-10%
- 空闲：3-5%
- 查询：8-12%
- 写入：10-15%

### 性能优化

```yaml
mysql:
  command: |
    --character-set-server=utf8mb4
    --collation-server=utf8mb4_unicode_ci
    --max_connections=500
    --innodb_buffer_pool_size=1G
    --innodb_log_file_size=256M
    --innodb_flush_log_at_trx_commit=2
    --innodb_flush_method=O_DIRECT
    --query_cache_type=0
    --query_cache_size=0
```

**说明**：
- `max_connections=500`：最大连接数
- `innodb_buffer_pool_size=1G`：缓冲池大小（建议为物理内存的50-70%）
- `innodb_log_file_size=256M`：重做日志文件大小
- `innodb_flush_log_at_trx_commit=2`：每秒刷新一次日志（性能优先）
- `query_cache_type=0`：禁用查询缓存（MySQL 8.0已废弃）

### 备份与恢复

```bash
# 备份数据库
docker exec fitness_mysql mysqldump -u root -ppassword fitness_app > backup.sql

# 恢复数据库
docker exec -i fitness_mysql mysql -u root -ppassword fitness_app < backup.sql

# 备份到容器内
docker exec fitness_mysql sh -c 'mysqldump -u root -ppassword fitness_app > /tmp/backup.sql'

# 从容器复制出来
docker cp fitness_mysql:/tmp/backup.sql ./backup_$(date +%Y%m%d).sql
```

**Q1: 连接数不足**
```sql

SHOW STATUS LIKE 'Threads_connected';

-- 查看最大连接数
SHOW VARIABLES LIKE 'max_connections';

-- 增加最大连接数（需重启）

```

**Q2: 慢查询优化**

-- 启用慢查询日志

### redis.conf配置

```conf
# 基本配置
bind 0.0.0.0
protected-mode yes
port 6379
timeout 0

# 持久化配置
save 900 1       # 900秒内至少1次写入
save 300 10      # 300秒内至少10次写入
save 60 10000    # 60秒内至少10000次写入
stop-writes-on-bgsave-error yes
rdbcompression yes
rdbchecksum yes
dbfilename dump.rdb
dir /data

# 内存配置
maxmemory 512mb
maxmemory-policy allkeys-lru  # LRU淘汰策略

# AOF配置（可选）
appendonly no
appendfilename "appendonly.aof"
appendfsync everysec

# 慢查询日志
slowlog-log-slower-than 10000  # 10ms
slowlog-max-len 128
```
