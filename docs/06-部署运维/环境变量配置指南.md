## 📝 使用示例

### 1. Docker 环境变量文件 (.env)

```bash
# 生产环境配置
ENVIRONMENT=production
DEBUG=false

# 数据库连接

NEO4J_PASSWORD=${NEO4J_PASSWORD_SECRET}

# AI 模型
TEACHER_MODEL_API_KEY=${DEEPSEEK_API_KEY}

```

### 2. 代码中使用环境变量

```python
import os
from typing import Optional

class Config:
    """DAML-RAG 配置类"""

    # Neo4j 配置
    NEO4J_URI: str = os.getenv('NEO4J_URI', 'bolt://localhost:7687')
    NEO4J_USER: str = os.getenv('NEO4J_USER', 'neo4j')
    NEO4J_PASSWORD: str = os.getenv('NEO4J_PASSWORD', '')

    # MCP 配置
    MCP_POOL_TIMEOUT: int = int(os.getenv('MCP_POOL_TIMEOUT', '30'))
    MCP_POOL_MAX_RETRIES: int = int(os.getenv('MCP_POOL_MAX_RETRIES', '3'))

    # AI 模型配置
    TEACHER_MODEL_NAME: str = os.getenv('TEACHER_MODEL_NAME', 'deepseek-chat')
    STUDENT_MODEL_NAME: str = os.getenv('STUDENT_MODEL_NAME', 'qwen3:8b')

    # 安全配置
    ALLOW_DEMO_DATA: bool = os.getenv('ALLOW_DEMO_DATA', 'false').lower() == 'true'
    ENVIRONMENT: str = os.getenv('ENVIRONMENT', 'development')

    @classmethod
    def is_production(cls) -> bool:
        """判断是否为生产环境"""
        return cls.ENVIRONMENT == 'production'

    @classmethod
    def get_user_id(cls, request) -> Optional[int]:
        """从请求中获取用户ID（生产环境实现）"""
        if cls.is_production():
            # 从session或JWT token获取真实用户ID
            return request.session.get('user_id') or request.user.id
        else:
            # 测试环境可返回固定ID（仅用于开发）
            test_id = os.getenv('TEST_USER_ID')
            return int(test_id) if test_id else None
```

### 3. 替换硬编码示例

```python
# ❌ 之前的硬编码做法
user_id = 1  # 硬编码
profile = await client.get_user_profile(user_id=1)

# ✅ 现在的环境变量做法
config = Config()
user_id = config.get_user_id(request)  # 动态获取
if user_id:
    profile = await client.get_user_profile(user_id)
else:
    raise AuthenticationError("用户未认证")
```

### 启动时检查清单

```bash
# 必需的环境变量检查
echo "检查Neo4j配置: $NEO4J_URI"

echo "检查安全配置: $ALLOW_DEMO_DATA"
```

### Python 配置验证

```python
def validate_config() -> List[str]:
    """验证配置完整性"""
    errors = []

    # 检查必需配置
    required_vars = ['NEO4J_URI', 'QDRANT_HOST', 'TEACHER_MODEL_API_KEY']
    for var in required_vars:
        if not os.getenv(var):
            errors.append(f"缺少必需环境变量: {var}")

    # 生产环境特殊检查
    if Config.is_production():
        if Config.ALLOW_DEMO_DATA:
            errors.append("生产环境不允许启用演示数据")
        if not Config.TEACHER_MODEL_API_KEY:
            errors.append("生产环境必须设置AI模型API密钥")

    return errors
```

## 🚨 安全注意事项

### 1. 敏感信息管理
- 所有API密钥、密码必须通过环境变量注入
- 不要在代码中硬编码任何敏感信息
- 使用Docker secrets或Kubernetes secrets管理敏感配置

### 2. 生产环境安全
```bash
# 禁用所有测试和演示功能
ALLOW_DEMO_DATA=false
DEBUG=false
DEMO_MODE=false
```

### 3. 最小权限原则
- 数据库用户只授予必要权限
- API密钥使用最小作用域
- 网络访问限制在必要范围内
