# DAML-RAG 安全评估报告

**评估人**: 安全评估Agent
**评估日期**: 2026-02-19
**评估范围**: `daml-rag-server/src/` 全部安全相关模块（11个文件）
**总分: 6.3 / 10**

---

## 1. API安全 — 6.5 / 10

**优点:**
- `DualAuthMiddleware` 实现了 JWT + Legacy Token 双认证，迁移期设计合理，`hmac.compare_digest` 防止时序攻击
- `InternalJwtVerifier` 使用 PyJWT 标准库，HS256 签名验证 + issuer 校验 + 必填字段 require，异常层次清晰
- `FailClosedPermissionChecker` 严格遵循 fail-closed 原则，所有异常路径默认拒绝
- `InputValidator` 覆盖了 XSS、SQL注入、路径穿越、模板注入、eval/exec 等常见攻击向量
- `RateLimiter` 实现了分钟/小时/突发三级限流 + 自动黑名单机制
- 生产环境隐藏 `/docs`、`/redoc`、`/openapi.json`

**问题:**
- **[P0]** `server.py` 中 CORS 配置 `allow_origins=["*"]`，生产环境允许任意来源跨域请求
- **[P0]** 认证默认关闭：`ENABLE_AUTH` 环境变量默认 `"false"`，漏配则完全无认证
- **[P1]** `RateLimiter` 纯内存实现，多实例部署时限流失效
- **[P1]** `PermissionChecker._check_usage()` 异常时 fail-open，与 fail-closed 权限检查不一致
- **[P2]** Debug 端点暴露环境变量
- **[P2]** 无 backend_client 时默认无限权限

---

## 2. 内容安全 — 4.5 / 10

**优点:**
- `ContentSafetyFilter` 架构设计合理：5 级风险等级、6 个内容分类、关键词 + 正则双重检测
- 医疗类关键词（30+）和危险行为关键词（12+）已填充

**问题:**
- **[P0]** 政治敏感、违法内容、不当内容三个关键词集合为空 `set()`，形同虚设
- **[P0]** 完全没有 Prompt Injection 防御机制
- **[P1]** 仅依赖关键词匹配，缺乏语义级内容理解
- **[P2]** LLM 输出端没有独立安全过滤层

---

## 3. 数据安全 — 7.0 / 10

**优点:**
- Fernet 加密（AES-128-CBC + HMAC-SHA256）
- PBKDF2HMAC + SHA256 + 32字节盐 + 100K 迭代
- `secrets` 模块生成密码学安全令牌
- `DataMasker` 覆盖邮箱/手机号/身份证号/Token 脱敏
- `SecurityLogger` 自动日志脱敏

**问题:**
- **[P1]** `PasswordHasher.verify_password()` 使用 `==` 比较哈希值，存在时序攻击风险
- **[P1]** `PermissionClaims.is_expired()` 使用 naive datetime，无时区感知
- **[P2]** `DataMasker` 在两个文件中重复实现
- **[P2]** 加密密钥无持久化，重启后无法解密旧数据

**优点:**

**问题:**
- **[P0]** `ContentSafetyFilter` 完全没有测试

- **[P1]** `InternalJwtVerifier`、`FailClosedPermissionChecker` 没有测试
- **[P1]** 没有 CORS 配置的集成测试
- **[P2]** 缺少端到端认证→权限→限流完整链路测试

---

## Top 3 改进建议

### 1. [紧急] 修复 CORS 配置 + 认证默认值

`allow_origins=["*"]` 改为白名单，`ENABLE_AUTH` 默认值改为 `"true"`。两个问题组合意味着漏配环境变量时任何来源可无认证访问所有 API。修复成本极低，安全收益极高。

### 2. [高优] 补全内容安全防线：关键词集合 + Prompt Injection 防御

三个空关键词集合必须填充（合规硬性要求）。增加 Prompt Injection 基础防御：系统提示词隔离、输出格式校验、已知注入模式检测。

### 3. [高优] 补充核心安全组件测试覆盖

`DualAuthMiddleware`、`ContentSafetyFilter`、`InternalJwtVerifier`、`FailClosedPermissionChecker` 全部缺失测试，需优先补充。

---

**结论**: 安全架构骨架合理（双认证、fail-closed、分层防御），但存在多处"骨架搭好、血肉未填"的情况。修复 Top 3 后预计总分可提升至 8.0+。
