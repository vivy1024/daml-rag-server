## 发现的问题

### 问题1: Promtail时间戳警告

**描述**: Promtail尝试发送旧日志时遇到"timestamp too old"错误

**影响**: 低 - 不影响新日志的采集

**原因**: Loki有时间窗口限制（默认12小时），不接受太旧的日志

**解决方案**: 
- 这是正常行为，旧日志会被跳过
- 新日志正常采集和存储
- 如需采集历史日志，需要调整Loki配置中的`reject_old_samples_max_age`

### 问题2: API错误

**描述**: 测试请求返回500错误：`BaseModel.model_dump_json() got an unexpected keyword argument 'encoder'`

**影响**: 中 - 影响新请求的测试

**原因**: Pydantic版本兼容性问题

**解决方案**: 
- 这是代码问题，不是日志系统问题
- 需要修复API代码中的Pydantic调用
- 不影响日志系统的功能验证

## Grafana查询示例

### 基础查询

```logql
# 查询所有DAML-RAG日志
{job="daml-rag"}

# 查询特定时间范围
{job="daml-rag"} [1h]

# 查询ERROR日志
{job="daml-rag"} |= "ERROR"

# 查询特定组件
{job="daml-rag"} |= "model_cache_manager"
```

### 高级查询

```logql
# 查询启动相关日志
{job="daml-rag"} |= "🚀"

# 查询成功完成的操作
{job="daml-rag"} |= "✅"

# 查询错误和警告
{job="daml-rag"} |~ "ERROR|WARNING"

# 组合查询
{job="daml-rag"} |= "model" |= "加载"
```

### 链路追踪查询（示例）

```logql
# 通过request_id追踪（当有会话日志时）
{job="daml-rag"} |= "req_abc123"

# 通过user_id追踪
{job="daml-rag"} |= "user_id=2"

# 通过session_id追踪
{job="daml-rag"} |= "session_id=test_123"

# 查询特定请求的所有步骤
{job="daml-rag"} |= "req_abc123" |= "步骤"
```

### C. LogQL参考

**基本语法**:
```logql
{标签选择器} |= "搜索文本" | 过滤器 | 聚合函数
```

**常用操作符**:
- `|=`: 包含
- `!=`: 不包含
- `|~`: 正则匹配
- `!~`: 正则不匹配

**聚合函数**:
- `sum()`: 求和
- `rate()`: 速率
- `count()`: 计数
- `avg()`: 平均值
